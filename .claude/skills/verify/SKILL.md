# verify

## 実行する

```bash
pnpm type-check
pnpm vitest run
```

lint は pre-commit（husky + lint-staged）が見るので、ここでは実行しない。

## 失敗したとき

- 直し方が機械的に一つに決まる失敗（型エラー、import 漏れ、リネームの追従漏れ）は直す。直したら型チェックとテストの両方を再実行する。
- 次の直し方はしない。
  - テストの期待値を変える
  - テストを skip・削除する
  - `any` などで型を逃がす
- 判断が要る失敗（仕様の解釈が要る、ユーザーの変更を打ち消すことになる）は直さない。失敗したコマンドと出力を報告して止まる。
