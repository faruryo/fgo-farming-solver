## ADDED Requirements

### Requirement: アドバイザーのタブ切り替え (Advisor Tab Navigation)
システムは、「毎月の交換券・配布」と「イベント料理作成（水着2026）」を切り替えられるタブUIを提供しなければならない (SHALL)。

#### Scenario: タブの切り替え
- **WHEN** ユーザーが「イベント料理作成」タブを選択したとき
- **THEN** イベント食材の入力欄と料理作成の最適化結果画面が表示される。
- **WHEN** ユーザーが「毎月の交換券・配布」タブを選択したとき
- **THEN** 従来の素材選択アドバイザー（候補素材ピッカーおよび獲得可能総数入力）が表示される。

### Requirement: イベント食材所持数の入力と料理作成最適化 (Event Craft Optimization)
システムは、イベント食材（うちなー海鮮盛り、うちなーお肉盛り、うちなー野菜盛り）の所持数を入力し、ユーザーの素材不足状況とフリクエAP/周回効率に基づいて最適な料理作成配分を計算・提示しなければならない (SHALL)。

#### Scenario: 食材数の入力と最適化計算
- **WHEN** ユーザーが各食材の所持数を入力したとき
- **THEN** 整数線形計画法（ILP）により、手持ち食材の制約内で総削減量（AP または 周回数）が最大となる料理作成数の組み合わせが即座に算出される。
- **THEN** 各料理の作成推奨数、獲得できる素材名、消費する食材数、削減されるAPまたは周回数が表示される。
- **THEN** 作成後に余る各食材の残数が表示される。

#### Scenario: AP節約優先と周回数節約優先の適用
- **WHEN** 最適化モードが「AP節約優先」のとき
- **THEN** 各料理で得られる素材の価値をAP限界削減量（シャドウプライス）として総削減APを最大化する。
- **WHEN** 最適化モードが「周回数節約優先」のとき
- **THEN** 各料理で得られる素材の価値を周回数限界削減量（シャドウプライス）として総削減周回数を最大化する。

#### Scenario: マシュによるクラフトアドバイス表示
- **WHEN** 料理作成の最適配分が算出されたとき
- **THEN** マシュのセリフ枠に、最も効果の高い料理名や合計削減コスト（APまたは周回数）を含む具体的なアドバイス文章が表示される。

### Requirement: 食材使い切りオプション (Exhaust Ingredients Option)
システムは、不足素材の枠を超えて余った食材を単体価値の高い料理で使い切るかどうかを制御する「食材を使い切る」オプションを提供しなければならない (SHALL)。

#### Scenario: 食材使い切りが有効な場合
- **WHEN** 「食材を使い切る」が有効（ON）のとき
- **THEN** 不足素材を満たした後（または不足がない場合）でも、食材が残っている限り、単体AP/周回効率が最も高い料理を作成して食材余剰を最小化する。

#### Scenario: 食材使い切りが無効な場合
- **WHEN** 「食材を使い切る」が無効（OFF）のとき
- **THEN** ユーザーが不足している素材数を超えて料理を作成せず、不足分を満たした時点で食材の消費を停止する。

### Requirement: イベントクラフト設定の永続化 (Event Craft Configuration Persistence)
システムは、選択されたタブ、各食材の所持数、および食材使い切りオプションの設定をブラウザの localStorage に永続化しなければならない (SHALL)。

#### Scenario: クラフト設定の保存と復元
- **WHEN** ユーザーが食材所持数や使い切りオプションを変更したとき
- **THEN** 設定が即座に localStorage に保存される。
- **WHEN** ページがリロードされたとき
- **THEN** 前回入力した食材数や設定が復元されて表示される。
