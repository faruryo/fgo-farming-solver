## MODIFIED Requirements

### Requirement: 計画の対象外の品目の要る・要らない
システムは、「計画の対象外」の品目ごとに、利用者が「必要」と「不要」を選べる切り替えを設けなければならない (SHALL)。既定で交換する品目（伝承結晶とカルデアの夢火）には、判定が「使わない」「足りている（交換不要）」「あと N 個」「計画の対象外」のどれでも、同じ切り替えを設けなければならない (SHALL)。まだ選んでいない品目の初期値は、既定で交換する品目では「必要」、それ以外では「不要」とする。コード・リムーバー／オープナーやサーヴァントコインは既定で交換する品目に含めない。選んだ内容は品目ごとに端末に保存し、画面を開き直しても、別のイベントの交換所でも、同じ品目には同じ選択を使わなければならない (SHALL)。交換回数は、要る・要らないの選択とは別に、交換所の周回計算の入力の保存（event-shop-saved-inputs）に従ってイベントごとに保存する。切り替えは交換回数を変えてはならず (SHALL NOT)、次の不足素材のみの操作でだけ使う。保存した「必要」は、その時点で「計画の対象外」と判定された品目と、既定で交換する品目にだけ使い、それ以外の「使わない」「足りている」「あと N 個」になった品目や、状態を表示していない品目には使ってはならない (SHALL NOT)。

#### Scenario: 初期値
- **WHEN** 利用者が一度も選んだことのない計画の対象外の品目（既定で交換する品目を除く）を、交換所の画面で見たとき
- **THEN** その品目は「不要」になっている

#### Scenario: 既定で交換する品目の初期値
- **WHEN** 利用者が一度も選んだことのない伝承結晶と夢火の品目を、交換所の画面で見たとき
- **THEN** どちらの品目にも切り替えが表示され、「必要」になっている

#### Scenario: 使わない・足りている伝承結晶の切り替え
- **WHEN** 伝承結晶の育成計画での必要数が 0 のとき、または必要数が 2 で所持数が 5 のとき
- **THEN** 伝承結晶の品目に「使わない」または「足りている（交換不要）」と、「必要」と「不要」の切り替えが表示される

#### Scenario: 不足のある伝承結晶の切り替え
- **WHEN** 伝承結晶の育成計画での必要数が 5、所持数が 2 のとき
- **THEN** 伝承結晶の品目に「あと 3 個」と、「必要」と「不要」の切り替えが表示される

#### Scenario: 既定で交換する品目を不要にした選択が残る
- **WHEN** 利用者があるイベントの交換所で伝承結晶を「不要」にし、伝承結晶を並べる別のイベントの交換所を開いたとき
- **THEN** 別のイベントでも伝承結晶は「不要」になっている

#### Scenario: 選択が残る
- **WHEN** 利用者が呼符を「必要」に切り替えてから、交換所の画面を開き直したとき
- **THEN** 呼符は「必要」のままで、交換回数は開き直す前にそのイベントで入れていた回数のまま（入れていなければ 0）になる

#### Scenario: 計画の対象外でなくなった品目
- **WHEN** 利用者が以前「必要」にした品目（既定で交換する品目を除く）が、育成計画で扱う素材に加わって「使わない」と表示され、利用者が不足素材のみの操作をしたとき
- **THEN** その品目の交換回数は 0 になる

#### Scenario: 別のイベントでも同じ選択を使う
- **WHEN** 利用者があるイベントの交換所で呼符を「必要」にし、呼符を並べる別のイベントの交換所を開いたとき
- **THEN** 別のイベントでも呼符は「必要」になっている

#### Scenario: 切り替えても回数は変わらない
- **WHEN** 交換回数が 0 の計画の対象外の品目を、利用者が「必要」に切り替えたとき
- **THEN** その品目の交換回数は 0 のまま変わらない
