# Spec Delta

## MODIFIED Requirements

### Requirement: ストック込み計算のフラグ記録と badge 表示

システムは、在庫基準まで含めた目標で解いた計算に「ストック込み」の印を記録しなければならない (SHALL)。周回計算の API は、ストック込みの計算であることを示す引数を受け取り、その引数が真のときだけ、保存する計算に印を記録しなければならない (SHALL)。引数が無い、または真以外の値のときは印を記録してはならない (SHALL NOT)。

育成計算機は、周回目的「新規サーヴァントに備える」で周回計算へ送るとき、この引数を真にして送らなければならない (SHALL)。「今の育成を進める」と「素材全体の効率を見る」で送るとき、および個数を手入力して計算するときは、この引数を付けてはならない (SHALL NOT)。

システムは 1 回の計算を、解いた 1 つの目標のまま 1 件として保存・表示しなければならず (SHALL)、必要分とストック込みの 2 目標を同時に計算して 2 件 1 組で保存してはならない (SHALL NOT)。周回計算の API は、ストック込みの目標を別の引数で受け取って 2 件を保存してはならない (SHALL NOT)。

印の付いた計算には、結果ページと履歴の一覧で「ストック込み」badge を表示しなければならない (SHALL)。計算履歴のグラフでは、印の付いた計算を「ストック込み」の系列として扱い、印の無い計算の系列（「通常」）の線と達成予想に含めてはならない (SHALL NOT)。後方互換のため、印を持たない既存の計算は印なし（badge なし、「通常」の系列）として扱わなければならない (SHALL)。

#### Scenario: 備える目的で解いた計算に印が付く
- **WHEN** ユーザーが周回目的「新規サーヴァントに備える」で、育成計算機から周回計算へ送る
- **THEN** 在庫基準まで含めた 1 つの目標だけが送られ、1 件の計算が「ストック込み」の印付きで保存される

#### Scenario: 今の育成で解いた計算には印が付かない
- **WHEN** ユーザーが周回目的「今の育成を進める」または「素材全体の効率を見る」で、育成計算機から周回計算へ送る
- **THEN** 保存される計算に「ストック込み」の印は付かない

#### Scenario: 手入力の計算には印が付かない
- **WHEN** ユーザーが育成計算機を経由せず個数を手入力して周回計算を実行する
- **THEN** 周回目的の選択にかかわらず、保存される計算に「ストック込み」の印は付かない

#### Scenario: ストック込みの目標を別の引数で送っても 2 件にならない
- **WHEN** 周回計算の API が、ストック込みの目標を別の引数で渡す古い形の要求を受け取る
- **THEN** その引数は使われず、通常の目標で解いた 1 件だけが保存される

#### Scenario: ストック込み履歴に badge
- **WHEN** 「ストック込み」の印付きで保存された計算を履歴/結果で表示する
- **THEN** 「ストック込み」badge が表示される

#### Scenario: 通常履歴は badge なし
- **WHEN** 印の無い計算を表示する
- **THEN** badge は表示されず、解いた目標がそのまま表示される

#### Scenario: グラフで系列が分かれる
- **WHEN** ログインユーザーの計算履歴に、印の無い計算と「新規サーヴァントに備える」で解いた印付きの計算の両方がある
- **THEN** 計算履歴のグラフは「通常 / ストック込み」を切り替えられ、「通常」の線と達成予想には印付きの計算が含まれず、「ストック込み」の線と達成予想には印の無い計算が含まれない

#### Scenario: 既存履歴の後方互換
- **WHEN** 印を持たない既存の保存データを表示する
- **THEN** エラーなく印なしとして扱われ、badge は表示されず、グラフでは「通常」の系列に入る

## REMOVED Requirements

### Requirement: 2目標の batch 連結保存
**Reason**: 必要分とストック込みの 2 目標を同時に計算して 2 件 1 組で保存する動きは 2026-10-17 の farming-purpose-modes で外れ、戻さないと決めた（#270）。計算は選んだ周回目的の 1 つの目標で行い、1 件で保存する。
**Migration**: 「新規サーヴァントに備える」で解いた計算は、1 件のまま「ストック込み」の印を付けて保存する（「ストック込み計算のフラグ記録と badge 表示」の要件）。過去に 2 件 1 組で保存された計算は消さず、「batch ペアの集約表示」「batch_id 後方互換」「計算履歴の論理削除」の要件のとおり、今までと同じに表示・削除できる。
