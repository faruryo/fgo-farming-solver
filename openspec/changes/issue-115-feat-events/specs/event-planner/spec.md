## ADDED Requirements

### Requirement: ポイント報酬とミッションの取り込み
システムは、イベントデータの取り込みで KV (`event_data_json`) に保存するイベントについて、Atlas Academy の `nice_event` のポイント報酬（`rewards`）とミッション（`missions`）もコンパクト化して保存しなければならない (SHALL)。取り込むイベントの条件は変えない (SHALL)。

ポイント報酬は、必要な累計ポイントの昇順に、累計ポイントと報酬（品目 ID・個数・種類）を保存しなければならない (SHALL)。ミッションは、表示順に、ミッション ID・表示名・報酬（品目 ID・個数・種類）・達成条件の要点（条件の種類・対象 ID・必要数）を保存しなければならない (SHALL)。報酬の種類は、素材などのアイテムと、サーヴァント・コマンドコードなどの素材以外を区別できなければならない (SHALL)。報酬のアイテムには、交換所と同じ方法で名前とアイコンを付けなければならない (SHALL)。

システムは、イベントの周回クエストのドロップに含まれるイベントポイントの品目（Atlas の品目の種類が `eventPoint` のもの）の ID を、そのイベントのポイントの品目として保存しなければならない (SHALL)。該当する品目が無いときは保存しない (SHALL)。

ポイント報酬・ミッション・ポイントの品目を持たない既存の KV のエントリーは、それぞれ空（または無し）として読まなければならず (SHALL)、読み込みに失敗してはならない (SHALL NOT)。ポイント報酬やミッションの取得・整形に失敗しても、そのイベントの交換所・ロト・周回クエストの取り込みを止めてはならない (SHALL NOT)。

#### Scenario: ポイント報酬のあるイベント
- **WHEN** 取り込み対象のイベントの `rewards` に、累計1,000ポイントで赤銅の果実1個などの報酬が180件ある
- **THEN** KV のそのイベントに、累計ポイントの昇順で180件のポイント報酬が、品目 ID・個数・種類と、アイテムなら名前とアイコンつきで保存される

#### Scenario: ミッションのあるイベント
- **WHEN** 取り込み対象のイベント（例: 80632）の `missions` に100件のミッションがある
- **THEN** KV のそのイベントに、表示順で100件のミッションが、表示名・報酬・達成条件の要点つきで保存される

#### Scenario: イベントポイントの品目
- **WHEN** イベントの周回クエストのドロップに、種類が `eventPoint` の品目（例: パンプキン収穫ポイント）がある
- **THEN** その品目の ID がイベントのポイントの品目として保存される

#### Scenario: 旧データの読み込み
- **WHEN** ポイント報酬・ミッションのフィールドが無い既存の KV のエントリーを読む
- **THEN** ポイント報酬とミッションは空、ポイントの品目は無しとして読まれ、イベントページはこれまでどおり表示される

#### Scenario: ミッションの取得に失敗
- **WHEN** あるイベントのミッションの整形が失敗する
- **THEN** そのイベントの交換所・ロト・周回クエストはこれまでどおり保存され、ミッションは空になる
