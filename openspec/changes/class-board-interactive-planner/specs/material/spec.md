## ADDED Requirements

### Requirement: マス単位クラススコア目標の素材計算結果への動的合算
システムは、クラスボード盤面上でマス単位に設定された目標必要素材を、サーヴァント育成計算結果（`MATERIAL_RESULT`）および周回ソルバーへ動的に合算して反映しなければならない (SHALL)。

#### Scenario: マス単位目標の素材計算への合算
- **GIVEN** クラスボード詳細画面で特定のマス群が「目標」に設定されている
- **WHEN** ユーザーが育成素材計算を実行したとき、または素材結果画面（`/material/result`）を表示したとき
- **THEN** クラスボード盤面の目標マス（未解放分）に必要な通常素材、ピース・モニュメント、QP、星光の砂、トーチが、サーヴァント育成必要素材と正しく合算される。
- **THEN** 周回ソルバー（`/farming`）の必要素材パラメータにも合算された数が反映され、最適周回クエストの算出対象となる。
