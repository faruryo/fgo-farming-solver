## Why

カードの小窓（#275 / PR #289）の Lv・宝具Lv の欄は文字の欄で、打った内容を保存のときに確かめている。デスクトップで日本語入力のまま打つと全角（９０）になり、範囲外として保存できない（修正前のコードで `readField('lv', '９０')` が範囲外と読まれることを確かめた）。オーナーの決定（2026-11-18）は、欄を Base UI の `NumberField`（`@base-ui/react`、導入済み）で作り、全角の数字は部品が半角に直して受け付けてよい、というもの。

## What Changes

- `components/ui/` に `NumberField` の薄い包みを足し、カードの小窓と、スクリーンショットの取り込みの確かめ画面（#260 / PR #274）の Lv・宝具Lv の欄をそれで作る
- 全角の数字は部品が半角に直して受け付ける（日本語入力のまま「９０」と打つと 90 になる）
- 数でない文字（英字・ひらがななど）は部品が欄に入れない。数として読めない貼り付け（「Lv 90」など）は無視され、欄の値は変わらない
- 範囲外の値（Lv 121・0、宝具Lv 6）と整数でない値は、最小・最大に丸めず、今までどおり赤枠で示して保存・取り込みに入れない
- スマホでは数字のキーボードを出す
- 交換所の残りや所持数など、ほかの数字の欄は変えない

## Capabilities

（なし）

### Modified Capabilities

- `servant-roster-screenshot-import`: Lv・宝具Lv の欄を数の部品で受ける要件を足す。「カードから Lv・宝具Lv を手で入れる」の範囲の判定（範囲外は保存できない）は変えない

## Impact

- `components/ui/`（数の欄の包みを足す）、`components/material/servant-level-dialog.tsx`、`components/material/servant-roster-review.tsx` の欄
- 範囲（Lv 1〜120、宝具Lv 1〜5 の整数）は変えない。保存値の形も変えない
- 取り込み・判定の条件は変えないので、対象件数は数えない
