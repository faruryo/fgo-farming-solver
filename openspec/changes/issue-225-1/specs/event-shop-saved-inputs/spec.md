# Spec Delta

## MODIFIED Requirements

### Requirement: 交換回数を品目に結び付けて保存する
システムは、交換回数を、交換所の並びの位置ではなく、品目を見分ける組（獲得物がアイテムかサーヴァント扱いか、獲得物の番号、1回の交換で得る個数、対価の通貨、1回の交換の対価の個数、交換所の中で同じ組を持つ品目どうしの並び）に結び付けて保存しなければならない (SHALL)。イベントデータの取り込み直しで交換所の品目の並びが変わっても、保存した回数は同じ組の品目に使わなければならず (SHALL)、別の品目に使ってはならない (SHALL NOT)。今の交換所に同じ組の品目が無い保存値は使ってはならない (SHALL NOT)。在庫上限のある品目では、保存した回数が今の在庫上限を超えるときは在庫上限の回数として使わなければならない (SHALL)。所持数とボーナスは、通貨または品目の番号に結び付けて保存し、今の交換所の欄に無い番号の保存値は使ってはならない (SHALL NOT)。複数の通貨で交換できる品目を1行にまとめた行（`event-shop-single-list`）の交換回数は、まとめた行としてではなく、通貨ごとの品目の交換回数として、上と同じ組に結び付けて保存しなければならない (SHALL)。まとめた行を表示する前に保存した交換回数は、変換せずにそのまま通貨ごとの品目の交換回数として使わなければならない (SHALL)。ボーナス礼装の ☆ ごとの入力は ☆ に結び付けて保存し、今のイベントの通貨と ☆ の対応に無い ☆ の保存値は使ってはならない (SHALL NOT)。保存したフレンドの礼装の ☆ が今の対応に無いときは、選んでいないものとして初期値（対応のある最も高い ☆）を使わなければならない (SHALL)。保存した選んだ行の合計枚数が、開いたときの比較の表に無いときは、AP が最も少ない行を選んだものとして表示し (SHALL)、利用者が値を変えるまでは保存値を書き換えてはならない (SHALL NOT)。

#### Scenario: 並びが変わった交換所
- **WHEN** 利用者が品目 A の交換回数に 3 を入れたあと、取り込み直しで品目 A の前に新しい品目が加わり、交換所を開き直したとき
- **THEN** 品目 A の交換回数は 3 で、新しい品目の交換回数は 0 になっている

#### Scenario: 同じ獲得物で個数や対価の違う品目が前に加わる
- **WHEN** 利用者が、獲得物 S を1回に1個・通貨 C を5個で交換する品目に 3 を入れたあと、取り込み直しでその前に、獲得物 S を1回に10個・通貨 C を40個で交換する品目が加わり、交換所を開き直したとき
- **THEN** 1回に1個の品目の交換回数は 3 のままで、加わった品目の交換回数は 0 になっている

#### Scenario: 同じ獲得物が同じ通貨で2つ並ぶ
- **WHEN** 同じ獲得物を同じ個数・同じ通貨・同じ対価で交換する品目（在庫上限だけが違う）が2つ並び、利用者が1つ目に 2、2つ目に 5 を入れてから開き直したとき
- **THEN** 1つ目は 2、2つ目は 5 のままで、入れ替わらない

#### Scenario: 無くなった品目
- **WHEN** 利用者が交換回数を入れた品目が、取り込み直しで交換所から無くなったあと、交換所を開き直したとき
- **THEN** その保存値はどの品目にも使われず、ほかの品目の交換回数と必要量は保存値の無い品目を除いた値で表示される

#### Scenario: 在庫上限が減った品目
- **WHEN** 利用者が在庫上限 10 の品目の交換回数に 10 を入れたあと、取り込み直しでその品目の在庫上限が 5 になり、交換所を開き直したとき
- **THEN** その品目の交換回数は 5 として表示され、必要量も 5 回分で計算される

#### Scenario: まとめた行の回数を通貨ごとに保存する
- **WHEN** 利用者が 80632 の交換所で月より団子の行に 4 を入れてから、ページを読み込み直したとき
- **THEN** 武蔵うどんの月より団子の品目は 2、江戸むすびの品目は 1、東干し柿の品目は 1 として保存されていて、月より団子の行は 4 と表示される

#### Scenario: まとめる前の保存値
- **WHEN** 交換所を通貨ごとのカードで表示していたときに、利用者が江戸むすびの月より団子に 1 と武蔵うどんのサーヴァントコインに 16 を入れていて、その後に交換所を開いたとき
- **THEN** 月より団子の行は 1、サーヴァントコインの行は 16 と表示され、江戸むすびと武蔵うどんの必要量は保存した回数のときと同じになる
