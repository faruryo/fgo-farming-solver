## ADDED Requirements

### Requirement: ページ見出しの共通コンポーネント
`components/common/page-header.tsx` の `PageHeader` が、ページ見出し（戻るリンク・英字ラベル・タイトル）を描く共通コンポーネントとして機能しなければならない (SHALL)。戻るリンクは、文言を渡したときだけ出し、戻り先を指定しなければ `/` へ戻る。タイトルの下に並べる要素と、タイトルの右側に並べる要素を渡せる。右側の要素は、見出しの下線の上で、タイトルと左右に並ぶ。

#### Scenario: 戻るリンクの無い見出し
- **WHEN** 戻るリンクの文言を渡さずに見出しを描く
- **THEN** 英字ラベルとタイトルだけが出て、戻るリンクは出ない

#### Scenario: 戻り先を指定した見出し
- **WHEN** 戻るリンクの文言と戻り先 `/events` を渡して見出しを描く
- **THEN** 戻るリンクが文言とともに出て、押すと `/events` へ移る

#### Scenario: 戻り先を指定しない見出し
- **WHEN** 戻るリンクの文言だけを渡して見出しを描く
- **THEN** 戻るリンクは `/` へ移る

#### Scenario: タイトルの右側に要素を並べる
- **WHEN** サーヴァント詳細ページを開く
- **THEN** STARS と CLASS がタイトルの右側に、今までと同じ位置で並ぶ

---

### Requirement: ページ見出しの統一
サーヴァント一覧・サーヴァント詳細・アイテム一覧・アイテム詳細・ドキュメント・クラウドセーブ・周回効率計算・計算結果・イベントのページ・イベントのデータ未取得の表示の見出しは、ページ見出しの共通コンポーネントを使わなければならない (SHALL)。これらのページは英字ラベルとタイトルを独自に組み立てない。置き換えの前後で、各ページの見出しの表示（戻るリンクの有無と戻り先、文言、右側の要素、並び）は変わらない。

#### Scenario: 戻るリンクの無いページ
- **WHEN** サーヴァント一覧・サーヴァント詳細・アイテム一覧・アイテム詳細・ドキュメント・クラウドセーブ・周回効率計算・計算結果のページを開く
- **THEN** 見出しに戻るリンクは出ず、英字ラベルとタイトルが今までと同じ見た目で出る

#### Scenario: イベント一覧へ戻るページ
- **WHEN** イベントのページ、またはデータ未取得のイベントのページを開く
- **THEN** 見出しに「イベント一覧へ戻る」リンクが出て、押すと `/events` へ移る

#### Scenario: 計算結果の見出しの右側
- **WHEN** 自分の計算結果のページを開く
- **THEN** 公開設定と計算履歴へのリンクが、今までと同じくタイトルの右側に出て、狭い幅では折り返す
