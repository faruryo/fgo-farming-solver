## ADDED Requirements

### Requirement: 交換所で切り替えたあとのフォーカスの移し先
システムは、ロトの無い交換所イベントの交換所の周回計算で、品目名のポップアップで「欲しい」と「いらない」を切り替え、その品目の行が品目の一覧と畳んだ「いらない品目」の間を動いたとき、キーボードのフォーカスを次の移し先へ移さなければならない (SHALL)。フォーカスをページの先頭（どの要素にもフォーカスが無い状態）に落としてはならない (SHALL NOT)。

- 「いらない」にしたとき: 品目の一覧で、その行のすぐ後に並んでいた「欲しい」の行の品目名へ移す。すぐ後の行が無ければすぐ前に並んでいた行の品目名へ、一覧に「欲しい」の行が1つも残らなければ畳んだ「いらない品目」の開閉の見出しへ移す。順位と見出しの付く一覧では、見出しをまたいだ次の行（「効率順」の最後の行の次は「AP 換算なし」の最初の行）を、すぐ後の行として扱う
- 「いらない品目」から「欲しい」に戻したとき: 品目の一覧に戻ったその品目の行の品目名へ移す。戻した品目が最後の1件で、畳んだ「いらない品目」が表示されなくなるときも同じとする

ポップアップの中の「欲しい」「いらない」をキーボードで選んだときは、移した先の品目名が画面の外にあれば、見える位置までスクロールしなければならない (SHALL)。タップやクリックで選んだときもフォーカスは同じ移し先へ移すが、画面をスクロールしてはならない (SHALL NOT)。ポップアップで今と同じ設定を選んで行が動かないとき、または Esc キーでポップアップを閉じたときは、押した品目名へフォーカスを戻さなければならない (SHALL)。ポップアップの外の別の要素を押して閉じたときは、押した要素からフォーカスを動かしてはならない (SHALL NOT)。タップで操作したときの表示（行の並び、畳み、ポップアップの閉じ方、スクロールの位置）は、この要件で変えてはならない (SHALL NOT)。

#### Scenario: いらないにすると次の行の品目名へ移る
- **WHEN** 品目の一覧に呼符・聖杯・伝承結晶がこの順で並び、利用者がキーボードで聖杯の品目名のポップアップを開いて「いらない」を選んだとき
- **THEN** 聖杯の行は「いらない品目」に移り、フォーカスは伝承結晶の品目名にある

#### Scenario: 一覧の最後の行をいらないにする
- **WHEN** 利用者が品目の一覧の最後の行の伝承結晶を「いらない」にしたとき
- **THEN** フォーカスは、伝承結晶のすぐ前に並んでいた行の品目名にある

#### Scenario: 効率順の最後の行をいらないにする
- **WHEN** 品目の一覧が「効率順」と「AP 換算なし」に分かれていて、利用者が「効率順」の最後の行を「いらない」にしたとき
- **THEN** フォーカスは「AP 換算なし」の最初の行の品目名にある

#### Scenario: 最後の欲しいの行をいらないにする
- **WHEN** 品目の一覧に「欲しい」の行が1つだけ残っていて、利用者がその行を「いらない」にしたとき
- **THEN** 品目の一覧に行は無くなり、フォーカスは畳んだ「いらない品目」の開閉の見出しにある

#### Scenario: いらない品目から欲しいに戻す
- **WHEN** 「いらない品目」に聖杯と呼符があり、利用者が開いた「いらない品目」で聖杯の名前のポップアップを開いて「欲しい」を選んだとき
- **THEN** 聖杯の行が品目の一覧に戻り、フォーカスは一覧の聖杯の品目名にあって、その品目名が画面に見えている

#### Scenario: 最後の1件を欲しいに戻す
- **WHEN** 「いらない品目」が聖杯の1件だけで、利用者が聖杯を「欲しい」に戻したとき
- **THEN** 「いらない品目」は表示されなくなり、フォーカスは品目の一覧の聖杯の品目名にある

#### Scenario: タップで欲しいに戻す
- **WHEN** 表の下の開いた「いらない品目」が画面に見えていて、表の聖杯の戻る位置が画面の上の外にあるときに、利用者が聖杯の名前をタップして「欲しい」をタップしたとき
- **THEN** 聖杯の行は品目の一覧に戻り、フォーカスは一覧の聖杯の品目名にあって、画面はスクロールしない

#### Scenario: 同じ設定を選ぶか Esc で閉じる
- **WHEN** 利用者が「欲しい」の呼符の品目名のポップアップで「欲しい」を選んだとき、または Esc キーでポップアップを閉じたとき
- **THEN** 呼符の行は動かず、フォーカスは呼符の品目名にある

#### Scenario: ポップアップの外を押して閉じる
- **WHEN** 呼符の品目名のポップアップを開いたまま、利用者が別の行の交換回数の入力欄を押したとき
- **THEN** ポップアップが閉じ、フォーカスはその入力欄にある
