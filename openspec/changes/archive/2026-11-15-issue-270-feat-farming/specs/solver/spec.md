# Spec Delta

## REMOVED Requirements

### Requirement: 2目標結果の進捗アンカー
**Reason**: 必要分とストック込みの 2 目標を同時に計算する動きは 2026-10-17 の farming-purpose-modes で外れ、戻さないと決めた（#270）。計算は選んだ周回目的の 1 つの目標で行うので、2 目標のどちらを進捗の基準にするかを決める要件は当てはまる場面がない。
**Migration**: 進捗の基準は、周回目的に応じて送った 1 つの目標で解いた計算そのものになる（「周回目的に応じた育成計算結果の取り込み」の要件）。「新規サーヴァントに備える」で解いた計算には「ストック込み」の印が付き、計算履歴のグラフでは「通常」と別の系列になる（farming-history の「ストック込み計算のフラグ記録と badge 表示」の要件）。
