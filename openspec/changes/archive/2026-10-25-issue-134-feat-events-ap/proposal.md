# Proposal

## Why

ロトの無い交換所イベントの交換所の周回計算（#162、#165）では、選んだ交換に要る周回数と AP は出るが、交換所を全部交換するまでの量は通貨ごとにボタンを押して足し合わせないと分からない。AP をどれだけ回復すれば届くか（林檎の数）も出ない（issue #134、epic #129 の B2）。箱のあるイベントの箱計画は、すでに AP 予算（黄金の果実 → 聖晶石 → 課金額）を出している。

## What Changes

- 交換所の周回計算に、全通貨の在庫上限のある品目をまとめて在庫上限まで選ぶボタンを足す。在庫上限の無い品目は、#162 と同じく自動では選ばない
- 交換所の周回の合計 AP に対し、箱計画と同じ AP 予算（マスターレベルから出る最大 AP で割った回復の回数を、黄金の果実の所持数 → 聖晶石 → 課金額の順に割り当てる）を出す
- マスターレベルと黄金の果実の所持数は、箱計画と同じ保存先の値を使い、交換所の周回計算からも変えられるようにする
- #162 の交換回数・所持数・必要量・周回の内訳と、#165 の効率順の並び・区切り・上部の合計の1行は変えない

## Capabilities

### New Capabilities
- `event-shop-ap-budget`: ロトの無い交換所イベントの交換所の周回計算で、全部交換の操作と、周回の合計 AP に対する AP 予算（黄金の果実・聖晶石・課金額）を出す

### Modified Capabilities
（なし）
