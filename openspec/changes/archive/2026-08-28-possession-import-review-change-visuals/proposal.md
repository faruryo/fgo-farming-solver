## Why

スクリーンショット取り込みのレビュー一覧は、所持数が変わらない行と増減した行が同じ見た目・ほぼ同じ並びで混ざる。マイルーム全件を取り込むと変更なしが大半になるため、本当に確認したい増減と要確認が埋もれる。

## What Changes

- レビュー各行を、編集中の提案値と現在所持の差で **増加 / 減少 / 変更なし** の3種に分類し、色・左縁の模様・符号バッジで同時に区別する（色だけに頼らない）。
- 提案値が空・矛盾などで差を判定できない行は、増減分類より **要確認** を優先して見せる。
- 既定の並びを、要確認 → 増加（変動幅の大きい順）→ 減少（変動幅の大きい順）→ 変更なし に固定する。変更なしは折りたたみ可能にし、件数だけは常に見えるようにする。
- 一覧上部に件数サマリ（要確認 / 増加 / 減少 / 変更なし）を出し、表示を「すべて / 変更あり / 要確認」で切り替えられるようにする。
- 行の値を直したときは、分類・バッジ・並び・サマリをその場で更新する。
