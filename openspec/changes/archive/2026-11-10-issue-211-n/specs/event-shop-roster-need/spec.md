## MODIFIED Requirements

### Requirement: 交換所で埋まらない不足
システムは、育成計画の不足のある素材（QP を除く）のうち、交換所に品目があるものについて、優先素材の回数で埋まる素材の数と、不足のある素材の数を要約として表示しなければならない (SHALL)。優先素材の回数は「欲しい」の品目にだけ入るので、品目がすべて「いらない」の素材は埋まらない素材として数える。在庫上限まで交換しても不足が残る素材は、埋まらない素材として要約に数える。在庫上限まで交換しても残る不足の個数（「交換所では N 個足りない」）を、品目の行に表示してはならない (SHALL NOT)。交換所に品目の無い素材の不足と、計画の対象外の品目は、この要約に数えない。

#### Scenario: 在庫上限で埋まらない
- **WHEN** 素材 S の不足が 15 で、素材 S を1回に1個得る在庫上限 10 の「欲しい」の品目だけがあるとき
- **THEN** 要約では素材 S は埋まらない素材として数えられ、その品目の行には「育成にあと 15 個」だけが出て、「交換所では 5 個足りない」は表示されない

#### Scenario: 要約
- **WHEN** 交換所に品目のある素材のうち3つに不足があり、そのうち2つが優先素材の回数で埋まるとき
- **THEN** 「育成計画の不足 3 素材のうち、交換所で埋まるのは 2 素材」と要約が表示される

#### Scenario: いらない品目しかない素材
- **WHEN** 素材 S の不足が 5 で、素材 S の品目が1つだけあり、利用者がその品目を「いらない」にしているとき
- **THEN** 要約で素材 S は埋まらない素材として数えられ、「交換所では N 個足りない」はどの行にも表示されない

#### Scenario: 最後の品目がいらないとき
- **WHEN** 素材 S の不足が 5 で、交換所の元の順に、素材 S を1回に1個得る在庫上限 3 の「欲しい」の品目 A と、在庫上限 10 の「いらない」の品目 B があり、利用者が優先素材の操作をしたとき
- **THEN** 品目 A の交換回数は 3 で、要約では素材 S は埋まらない素材として数えられ、品目 A の行に「交換所では 2 個足りない」は表示されない

### Requirement: 欲しい品目の要る・要らない
システムは、ロトの無い交換所イベントの交換所の品目を、このサイトの育成計画で扱う素材（育成計画が必要数を出しうる素材。QP を除く）と、それ以外の品目に分け、「欲しい」の品目ごとに次のどれかを表示しなければならない (SHALL)。育成計画で扱う素材は、育成計画の必要数から所持数を引いた不足（0 未満は 0）を求め、必要数が 1 以上で不足が 0 なら「足りている（交換不要）」、不足が 1 以上なら「育成にあと N 個」（N は不足）、必要数が 0 なら「使わない」と表示する。育成計画で扱わない品目（呼符・サーヴァントコイン・聖杯・コード・リムーバー・カルデアの夢火・他のイベントアイテムなど）は「計画の対象外」と表示する。育成計画で扱う素材の一覧を読み込めないときは、必要数が 0 の品目にラベルを表示せず、計画の対象外の品目を見分けられないことを表示しなければならない (SHALL)。ただし伝承結晶とカルデアの夢火は番号で扱いが決まっているので、一覧を読み込めないときも、伝承結晶は育成計画で扱う素材として、夢火は計画の対象外として、ラベルを表示しなければならない (SHALL)。QP の品目は対象に含めず、ラベルを表示しない。「いらない」の品目は、表の最後の畳んだ「いらない品目」（`item-want-setting`）に名前だけを出し、ラベルを表示しない。不足は品目が得る素材ごとに求め、交換所に同じ素材の品目が複数あっても同じ不足を表示する。育成計画と所持数は、育成計画のページと所持数のページで保存した値を読むだけとし、交換所の画面から書き換えてはならない (SHALL NOT)。

「足りている（交換不要）」と「使わない」の行は、交換回数が 0 のときは、ほかの行より薄い文字色で表示しなければならない (SHALL)。交換回数が 1 以上の行は、ラベルによらず薄い文字色にしてはならない (SHALL NOT)。

#### Scenario: 不足がある素材
- **WHEN** 育成計画で素材 S の必要数が 30、所持数が 25 のとき
- **THEN** 素材 S の品目に「育成にあと 5 個」と表示される

#### Scenario: 足りている素材
- **WHEN** 育成計画で素材 S の必要数が 30、所持数が 40 のとき
- **THEN** 素材 S の品目に「足りている（交換不要）」と表示される

#### Scenario: 育成計画で扱うが必要数が 0 の素材
- **WHEN** 品目が育成計画で扱う素材で、育成計画での必要数が 0 のとき
- **THEN** その品目に「使わない」と表示される

#### Scenario: 育成計画で扱わない品目
- **WHEN** 品目が呼符・コード・リムーバー・他のイベントアイテムのどれかのとき
- **THEN** その品目に「計画の対象外」と表示される

#### Scenario: 育成計画で扱う素材の一覧を読み込めないとき
- **WHEN** 育成計画は読み込めたが、育成計画で扱う素材の一覧を読み込めなかったとき
- **THEN** 不足のある素材と足りている素材にはラベルが表示され、伝承結晶と夢火を除く必要数が 0 の品目にはラベルが表示されず、計画の対象外の品目を見分けられないことが表示される

#### Scenario: 一覧を読み込めないときの伝承結晶と夢火
- **WHEN** 伝承結晶と夢火の育成計画での必要数が 0 で、育成計画で扱う素材の一覧を読み込めなかったとき
- **THEN** 伝承結晶の品目に「使わない」、夢火の品目に「計画の対象外」と表示される

#### Scenario: いらない品目にはラベルを出さない
- **WHEN** 育成計画で素材 S の不足が 5 で、利用者が素材 S の品目を「いらない」にしているとき
- **THEN** 素材 S の品目は表の最後の「いらない品目」に名前だけが出て、「育成にあと 5 個」は表示されない

#### Scenario: 回数を入れた行は薄くしない
- **WHEN** 伝承結晶の行が「使わない」で、利用者がその行の交換回数に 1 を入れたとき
- **THEN** 伝承結晶の行は、「育成にあと N 個」の行と同じ文字色で表示される
- **THEN** 利用者が回数を 0 に戻すと、伝承結晶の行は薄い文字色に戻る
