## Purpose

ユーザーがFGOの各クラス（9種）のクラススコア最大解放目標を設定し、必要な強化素材・ピース・モニュメント・QP・特殊アイテム（砂・トーチ）をシミュレーション・管理する機能。

## ADDED Requirements

### Requirement: クラススコア目標ステータスの管理
システムは、全9クラス（セイバー、アーチャー、ランサー、ライダー、キャスター、アサシン、バーサーカー、EX1、EX2）それぞれについて、クラススコアの目標ステータス（未設定 `none`、最大目標 `target`、解放済み `completed`）を管理し、ローカルストレージへ永続化しなければならない (SHALL)。

#### Scenario: クラスごとの目標ステータス切替
- **WHEN** ユーザーが特定クラスのカード上で「目標にする」を選択したとき
- **THEN** そのクラスのステータスが `target` に更新され、必要素材集計の対象に含まれる。
- **THEN** 変更内容は `localStorage` の `classScore` キーへ保存され、`ls-sync` イベントが発火する。

#### Scenario: 解放済みへのステータス変更
- **WHEN** ユーザーが特定クラスのカード上で「解放済み」を選択したとき
- **THEN** そのクラスのステータスが `completed` に更新され、必要素材集計からは除外される。

#### Scenario: 未設定へのリセット
- **WHEN** ユーザーが特定クラスのカード上で「未設定」を選択したとき
- **THEN** そのクラスのステータスが `none` に戻り、必要素材集計から除外される。

### Requirement: クラススコア必要素材の算出
システムは、ステータスが `target` に設定されている全クラスについて、最大解放に必要な素材（通常強化素材、ピース、モニュメント、QP、星光の砂、新星/明星/極星のトーチ）を正確に集計しなければならない (SHALL)。

#### Scenario: 単一クラスの必要素材算出
- **GIVEN** セイバークラスのみが `target` に設定されている
- **WHEN** 必要素材が集計されるとき
- **THEN** QP 3億1,700万、セイバーピース 140個、セイバーモニュメント 500個、通常素材（英雄の証 70個、竜の牙 70個等）、星光の砂 6,680個、新星のトーチ 4個、明星のトーチ 4個、極星のトーチ 2個が算出される。

#### Scenario: 複数クラスの必要素材合算
- **GIVEN** セイバーとバーサーカーが `target` に設定されている
- **WHEN** 必要素材が集計されるとき
- **THEN** 両クラスで共通して要求される素材（虚影の塵など）やQP・星光の砂・トーチは合算され、各クラス固有のピース・モニュメントはそれぞれの必要数が計上される。

### Requirement: 破壊的操作の防止と安全確認
システムは、一括リセットなどの破壊的操作に対して二段階確認ダイアログ（`AlertDialog`）を要求し、日常利用しない一括完了操作を提供せず、実行後のUndo手段を提供しなければならない (SHALL)。

#### Scenario: 一括リセット時の確認モーダル表示
- **WHEN** ユーザーが詳細メニューから「一括リセット」をクリックしたとき
- **THEN** 即時実行はされず、警告説明を含む確認ダイアログ（`AlertDialog`）が表示される。
- **THEN** 「キャンセル」を押した場合は状態は変更されない。

#### Scenario: 一括リセット実行後のUndo復帰
- **WHEN** ユーザーが確認ダイアログでリセットを確定したとき
- **THEN** 全クラスの設定が `none` にリセットされる。
- **THEN** 画面下部に「元に戻す」アクションを含むトースト通知が表示される。
- **THEN** トースト内の「元に戻す」をクリックしたとき、リセット直前の状態が完全に復元される。

#### Scenario: 一括完了ボタンの非表示
- **WHEN** クラススコア画面を表示したとき
- **THEN** 誤操作リスク防止のため、画面上に「全クラス完了」の一括操作ボタンは表示されない (SHALL NOT)。

### Requirement: クラススコア画面へのアクセス導線
システムは、クラススコア目標シミュレータへの恒常的なナビゲーション導線を提供しなければならない (SHALL)。孤立ルート（オーファンページ）であってはならない。

#### Scenario: ナビゲーションメニューからの遷移
- **WHEN** ユーザーがナビゲーションメニュー（`nav.tsx`）または育成素材計算機ヘッダーのクラススコアリンクをクリックしたとき
- **THEN** クラススコア目標シミュレータ画面（`/material/class-score`）へ遷移する。
