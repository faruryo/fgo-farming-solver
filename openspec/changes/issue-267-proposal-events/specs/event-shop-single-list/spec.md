## MODIFIED Requirements

### Requirement: 交換所の品目を1つの一覧で並べる
システムは、イベントページの交換所タブの周回計算で、品目を対価の通貨ごとのカードに分けず、1つの一覧として表示しなければならない (SHALL)。一覧の行の並びは `event-shop-efficiency` の「効率順の1つの一覧」に従う。「欲しい」の品目の各行には、品目の名前とアイコン、交換回数の入力、1回の個数、在庫上限（無いときは上限なし）、対価の通貨の名前またはアイコンと1回の対価の数を表示しなければならない (SHALL)。品目ごとに出す育成計画の表示（計画の状態）は、今までどおり「欲しい」の品目の行に出さなければならない (SHALL)。交換所で埋まらない不足は、`event-shop-roster-need` の「交換所で埋まらない不足」のとおり要約にだけ出し、品目の行には出さない。「いらない」の品目は、`item-want-setting` の「いらない品目を表の最後に畳む」に従い、行と交換回数の入力を一覧から外して一覧の最後に畳む。

#### Scenario: 通貨ごとのカードが無い
- **WHEN** 80632 の交換所の周回計算を開いたとき
- **THEN** 武蔵うどん・江戸むすび・東干し柿の品目が通貨ごとのカードに分かれず、1つの一覧に並ぶ

#### Scenario: 行に対価の通貨が出る
- **WHEN** 東干し柿だけで交換できる叡智の業火の行を見たとき
- **THEN** その行の対価に、東干し柿の名前またはアイコンと 5 が出る

#### Scenario: いらない品目は一覧の行に出ない
- **WHEN** 利用者が 80632 の交換所で月より団子を「いらない」にしているとき
- **THEN** 1つの一覧に月より団子の行と入力欄は無く、一覧の最後の「いらない品目」に月より団子の名前が入る
