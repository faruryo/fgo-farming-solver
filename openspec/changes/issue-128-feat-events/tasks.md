- [ ] 1.1 `lib/event-shop-summary.ts` に、品目ごとの交換回数（在庫上限で頭打ち、在庫上限の無い品目は入れた回数）から通貨ごとの対価の合計を出し、通貨ごとの所持数を引いた必要量（0未満は0）を返す純粋関数と、通貨のグループで在庫上限のある品目を上限まで選んだ回数を返す純粋関数を足す（design の決定 2）。在庫上限を超える回数が頭打ちになること、在庫上限の無い品目が「上限まで選ぶ」で0のままになること、所持数で足りると必要量が0になることをユニットテストにする
