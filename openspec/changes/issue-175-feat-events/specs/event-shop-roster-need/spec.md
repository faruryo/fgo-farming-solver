## Purpose

ロトの無い交換所イベントの交換所で、育成計画の不足と所持数から品目ごとに交換が要るかどうかを示し、不足素材のみを交換したときの周回数と、交換所では埋まらない不足を分かるようにする。

## ADDED Requirements

### Requirement: 品目ごとの要る・要らない
システムは、ロトの無い交換所イベントの交換所の品目を、このサイトの育成計画で扱う素材（育成計画が必要数を出しうる素材。QP を除く）と、それ以外の品目に分け、品目ごとに次のどれかを表示しなければならない (SHALL)。育成計画で扱う素材は、育成計画の必要数から所持数を引いた不足（0 未満は 0）を求め、必要数が 1 以上で不足が 0 なら「足りている（交換不要）」、不足が 1 以上なら「あと N 個」（N は不足）、必要数が 0 なら「使わない」と表示する。育成計画で扱わない品目（呼符・サーヴァントコイン・聖杯・コード・リムーバー・他のイベントアイテムなど）は「計画の対象外」と表示する。育成計画で扱う素材の一覧を読み込めないときは、必要数が 0 の品目にラベルと切り替えを表示せず、計画の対象外の品目を見分けられないことを表示しなければならない (SHALL)。QP の品目は対象に含めず、ラベルを表示しない。不足は品目が得る素材ごとに求め、交換所に同じ素材の品目が複数あっても同じ不足を表示する。育成計画と所持数は、育成計画のページと所持数のページで保存した値を読むだけとし、交換所の画面から書き換えてはならない (SHALL NOT)。

#### Scenario: 不足がある素材
- **WHEN** 育成計画で素材 S の必要数が 30、所持数が 25 のとき
- **THEN** 素材 S の品目に「あと 5 個」と表示される

#### Scenario: 足りている素材
- **WHEN** 育成計画で素材 S の必要数が 30、所持数が 40 のとき
- **THEN** 素材 S の品目に「足りている（交換不要）」と表示される

#### Scenario: 育成計画で扱うが必要数が 0 の素材
- **WHEN** 品目が育成計画で扱う素材で、育成計画での必要数が 0 のとき
- **THEN** その品目に「使わない」と表示される

#### Scenario: 育成計画で扱わない品目
- **WHEN** 品目が呼符・コード・リムーバー・他のイベントアイテムのどれかのとき
- **THEN** その品目に「計画の対象外」と表示される

#### Scenario: 育成計画で扱う素材の一覧を読み込めないとき
- **WHEN** 育成計画は読み込めたが、育成計画で扱う素材の一覧を読み込めなかったとき
- **THEN** 不足のある素材と足りている素材にはラベルが表示され、必要数が 0 の品目にはラベルと切り替えが表示されず、計画の対象外の品目を見分けられないことが表示される

### Requirement: 計画の対象外の品目の要る・要らない
システムは、「計画の対象外」の品目ごとに、利用者が「要る」と「要らない」を選べる切り替えを設けなければならない (SHALL)。まだ選んでいない品目の初期値は「要らない」とする。選んだ内容は品目ごとに端末に保存し、画面を開き直しても、別のイベントの交換所でも、同じ品目には同じ選択を使わなければならない (SHALL)。交換回数は保存しない。切り替えは交換回数を変えてはならず (SHALL NOT)、次の不足素材のみの操作でだけ使う。保存した「要る」は、その時点で「計画の対象外」と判定された品目にだけ使い、「使わない」「足りている」「あと N 個」になった品目や、状態を表示していない品目には使ってはならない (SHALL NOT)。

#### Scenario: 初期値
- **WHEN** 利用者が一度も選んだことのない計画の対象外の品目を、交換所の画面で見たとき
- **THEN** その品目は「要らない」になっている

#### Scenario: 選択が残る
- **WHEN** 利用者が呼符を「要る」に切り替えてから、交換所の画面を開き直したとき
- **THEN** 呼符は「要る」のままで、交換回数は保存されず 0 から始まる

#### Scenario: 計画の対象外でなくなった品目
- **WHEN** 利用者が以前「要る」にした品目が、育成計画で扱う素材に加わって「使わない」と表示され、利用者が不足素材のみの操作をしたとき
- **THEN** その品目の交換回数は 0 になる

#### Scenario: 別のイベントでも同じ選択を使う
- **WHEN** 利用者があるイベントの交換所で呼符を「要る」にし、呼符を並べる別のイベントの交換所を開いたとき
- **THEN** 別のイベントでも呼符は「要る」になっている

#### Scenario: 切り替えても回数は変わらない
- **WHEN** 交換回数が 0 の計画の対象外の品目を、利用者が「要る」に切り替えたとき
- **THEN** その品目の交換回数は 0 のまま変わらない

### Requirement: 不足素材のみ
システムは、交換所の周回計算に「不足素材のみ」の操作を設けなければならない (SHALL)。操作をすると、すべての品目の交換回数を次のとおりに置き換える。不足のある素材について、交換所の元の順に品目を見て、まだ埋まっていない不足を「1回の交換で得る個数」で割って切り上げた回数を、在庫上限のある品目では在庫上限までで入れ、入れた回数で得る個数を不足から差し引いて次の品目へ進む。在庫上限の無い品目は上限で打ち切らない。「要る」を選んだ計画の対象外の品目は、在庫上限のある品目なら在庫上限の回数にし、在庫上限の無い品目なら 0 にして、回数を手で入れるよう示す。1回の交換で得る個数が 0 以下の品目と、それ以外の品目（足りている素材・使わない素材・「要らない」の計画の対象外の品目・QP の品目）は 0 にする。操作の後の必要量・周回の内訳・合計・AP 予算は、利用者が各品目に同じ回数を入れたときと同じでなければならない (SHALL)。操作の後も、利用者は各品目の交換回数を変えられなければならない (SHALL)。育成計画・所持数・要る・要らないの選択が変わっても、入れ終えた交換回数を操作なしに変えてはならない (SHALL NOT)。

#### Scenario: 不足の分だけ交換する
- **WHEN** 素材 S の不足が 5 で、素材 S を1回に1個得る在庫上限 10 の品目があり、利用者が不足素材のみの操作をしたとき
- **THEN** その品目の交換回数は 5 になり、足りている品目・使わない品目・「要らない」の計画の対象外の品目の交換回数は 0 になり、それに合う必要量と周回の合計が出る

#### Scenario: 1回に複数個得る品目
- **WHEN** 素材 S の不足が 5 で、素材 S を1回に3個得る在庫上限 10 の品目があるとき
- **THEN** 不足素材のみの操作で、その品目の交換回数は 2 になる

#### Scenario: 同じ素材の品目が複数あるとき
- **WHEN** 素材 S の不足が 5 で、交換所の元の順に、素材 S を1回に1個得る在庫上限 3 の品目と、在庫上限 10 の品目があるとき
- **THEN** 不足素材のみの操作で、前の品目の交換回数は 3、後の品目の交換回数は 2 になる

#### Scenario: 在庫上限の無い素材の品目
- **WHEN** 素材 S の不足が 7 で、素材 S を1回に1個得る在庫上限の無い品目だけがあるとき
- **THEN** 不足素材のみの操作で、その品目の交換回数は 7 になる

#### Scenario: 「要る」を選んだ計画の対象外の品目
- **WHEN** 在庫上限 1 のコード・リムーバーと、在庫上限の無い他のイベントアイテムをどちらも「要る」に選び、利用者が不足素材のみの操作をしたとき
- **THEN** コード・リムーバーの交換回数は 1 になり、他のイベントアイテムの交換回数は 0 になって、在庫上限が無いので回数を手で入れるよう示される

### Requirement: 交換所で埋まらない不足
システムは、育成計画の不足のある素材（QP を除く）のうち、交換所に品目があるものについて、不足素材のみの回数で埋まる素材の数と、不足のある素材の数を要約として表示しなければならない (SHALL)。在庫上限まで交換しても不足が残る素材は、その素材の品目のうち交換所の元の順で最後の品目に、残る個数を「交換所では N 個足りない」と表示しなければならない (SHALL)。交換所に品目の無い素材の不足と、計画の対象外の品目は、この要約に数えない。

#### Scenario: 在庫上限で埋まらない
- **WHEN** 素材 S の不足が 15 で、素材 S を1回に1個得る在庫上限 10 の品目だけがあるとき
- **THEN** その品目に「交換所では 5 個足りない」と表示され、要約では素材 S は埋まらない素材として数えられる

#### Scenario: 要約
- **WHEN** 交換所に品目のある素材のうち3つに不足があり、そのうち2つが不足素材のみの回数で埋まるとき
- **THEN** 「育成計画の不足 3 素材のうち、交換所で埋まるのは 2 素材」と要約が表示される

### Requirement: 育成計画が使えないとき
システムは、育成対象のサーヴァントが設定されていないときは、品目ごとの要る・要らないの表示・計画の対象外の品目の切り替え・要約を表示してはならず (SHALL NOT)、不足素材のみの操作を使えなくし、育成対象を設定するページへのリンクを表示しなければならない (SHALL)。育成計画の素材を読み込んでいる間は読み込み中と表示し、読み込みに失敗したときは失敗したことを表示して、どちらのときも要る・要らないを表示せず、操作を使えなくしなければならない (SHALL)。どの状態でも、交換回数の入力・全部交換・周回の内訳はこれまでどおり使えなければならない (SHALL)。

#### Scenario: 育成計画が未設定
- **WHEN** 育成対象のサーヴァントが1人も設定されていないとき
- **THEN** 品目に要る・要らないと切り替えは表示されず、不足素材のみの操作は押せず、育成対象を設定するページへのリンクが表示され、全部交換と交換回数の入力は使える

#### Scenario: 読み込みに失敗したとき
- **WHEN** 育成計画の素材の一部を取得できなかったとき
- **THEN** 失敗したことが表示され、品目に要る・要らないは表示されず、不足素材のみの操作は押せない
