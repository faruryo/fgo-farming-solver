# Proposal

## Why

ロトの無い交換所イベントの交換所では、品目ごとに交換回数を入れると周回数と AP が出る。しかし、自分の所持数からして交換しなくてよい品目はどれか、足りない素材だけを交換するなら何周すればよいかは、利用者が育成計画と所持数を見比べて手で数えるしかない（#175）。#133（育成計画の不足素材がイベントでどれだけ埋まるか）は、ロトのあるイベントの箱計画では roster モードとして出せるが、交換所だけのイベントでは出せない。

## What Changes

- 交換所の品目を、このサイトの育成計画で扱う素材と、扱わない品目に分ける。育成計画で扱う素材には、育成計画の必要数と所持数から「足りている（交換不要）」「あと N 個」「使わない」を表示する
- 育成計画で扱わない品目（呼符・聖杯・コード・リムーバー・他のイベントアイテムなど）には「計画の対象外」と表示し、利用者が品目ごとに「要る／要らない」を選べるようにする（初期値は「要らない」。選択は品目ごとに端末へ保存し、イベントをまたいで使う）。サイトが対応していないだけで、その人には要る品目があるため
- 「不足素材のみ」の操作を足す。足りない素材の分と、「要る」にした計画の対象外の品目の在庫上限の分を交換回数に入れ、既存の流れで必要量・周回の内訳・合計・AP 予算を出す
- 不足素材のみを交換したと仮定して（操作を押す前から）、交換所の在庫上限で埋まらない不足の品目と個数を示し、育成計画の不足のうち交換所で埋まる素材の数を要約する（#133 の交換所だけのイベント版）
- 育成計画が未設定・読み込み中・読み込みに失敗したときの表示を決める。未設定なら、要る・要らないを出さず、操作を使えなくし、育成対象を設定するページへのリンクを出す

## Capabilities

### New Capabilities

- `event-shop-roster-need`: ロトの無い交換所イベントの交換所で、育成計画の不足と所持数から品目ごとの要る・要らないを出し、計画の対象外の品目の要る・要らないを選ばせ、不足素材のみを交換したときの周回数と、交換所で埋まらない不足を出す

### Modified Capabilities

なし

## Impact

- `components/events/EventShopList.tsx`: 育成計画（`useRosterNeed`）・所持数（`STORAGE_KEYS.POSSESSION`）・素材カタログ（`useMaterialCatalog`）を読み、品目の行にラベルと計画の対象外の品目の切り替えを出し、上部の操作に「不足素材のみ」を足す
- `lib/event-shop-summary.ts`: 品目ごとの不足と状態、不足素材のみの交換回数、要約を出す純粋関数
- `lib/constants/storage-keys.ts`: 要る・要らないを保存するキー `events/shopWantedItems`（クラウド同期の対象外）
- `locales/ja.json`・`locales/en.json`
- #176 は #177 でマージ済み。この change は #177 の後の交換所の画面に乗る
