# Proposal

## Why

ロトの無い交換所イベントの交換所では、品目ごとに交換回数を入れると周回数と AP が出る。しかし、自分の所持数からして交換しなくてよい品目はどれか、要る品目だけを交換するなら何周すればよいかは、利用者が育成計画と所持数を見比べて手で数えるしかない（#175）。#133（育成計画の不足素材がイベントでどれだけ埋まるか）は、ロトのあるイベントの箱計画では roster モードとして出せるが、交換所だけのイベントでは出せない。

## What Changes

- 交換所の品目ごとに、育成計画の必要数と所持数から「足りている（交換不要）」「あと N 個要る」「育成計画で使わない」を表示する
- 「要るものだけ交換」の操作を足す。まだ要る分だけを交換回数に入れ、既存の流れで必要量・周回の内訳・合計・AP 予算を出す
- 要るものだけ交換したとき、交換所の在庫上限で埋まらない不足の品目と個数を示し、育成計画の不足のうち交換所で埋まる品目の数を要約する（#133 の交換所だけのイベント版）
- 育成計画が未設定・読み込み中・読み込みに失敗したときの表示を決める。未設定なら、要る・要らないを出さず、操作を使えなくし、育成対象を設定するページへのリンクを出す

## Capabilities

### New Capabilities

- `event-shop-roster-need`: ロトの無い交換所イベントの交換所で、育成計画の不足と所持数から品目ごとの要る・要らないを出し、要る分だけ交換したときの周回数と、交換所で埋まらない不足を出す

### Modified Capabilities

なし

## Impact

- `components/events/EventShopList.tsx`: 育成計画（`useRosterNeed`）と所持数（`STORAGE_KEYS.POSSESSION`）を読み、品目の行に要る・要らないを出し、上部の操作に「要るものだけ交換」を足す
- `lib/event-shop-summary.ts`: 品目ごとの不足と、要る分だけの交換回数を出す純粋関数
- `locales/ja.json`・`locales/en.json`
- #176（交換所の区切りの線と「効率の良いところまで交換」を消す）と同じ画面に触れるので、実装は #176 のマージ後に main から始める
