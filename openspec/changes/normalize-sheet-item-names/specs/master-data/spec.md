# Spec Delta

## MODIFIED Requirements

### Requirement: アイテム名のマッピング
システムは、スプレッドシート上の日本語略称を Atlas Academy の正式名称に正確に変換しなければならない (SHALL)。略称の全角・半角の違い（半角カナ「ｶｹﾗ」と全角「カケラ」など）は変換結果を変えてはならない (MUST NOT)。

#### Scenario: 名称変換の実行
- **WHEN** マッピングルール（静的テーブル、パターン変換、フォールバック）が適用されるとき
- **THEN** 略称（例: 「証」）が正式名称（例: 「英雄の証」）に変換される。

#### Scenario: 半角カナの略称も同じ正式名称に変換される
- **WHEN** スプレッドシートの見出しが半角カナの略称（例: 「ｶｹﾗ」「ｴｰﾃﾙ」）であるとき
- **THEN** 全角で書いた場合と同じ正式名称（例: 「煌星のカケラ」「エーテル収光体」）に変換される。
- **THEN** その列の素材は items に載り、列のドロップ率は drop_rates に含まれる。

#### Scenario: 静的テーブルに半角で登録済みの略称は従来どおり変換される
- **WHEN** 見出しが「ﾗﾝﾀﾝ」のように静的テーブルへ半角で登録済みの略称であるとき
- **THEN** 変換結果は変更前と同じ正式名称（例: 「ゴーストランタン」）である。

## ADDED Requirements

### Requirement: 周回対象素材の欠落を更新ログに出す
システムは、`all_drops_json` を書き込む前に、Atlas Academy の周回対象素材（`skillLvUp` 型で銅・銀・金、priority 298 以下）のうち変換結果の items に無いもの、または正のドロップ率が1件も無いものを一覧し、更新ジョブのログに警告として出さなければならない (SHALL)。この警告は KV への書き込みを止めてはならない (MUST NOT)。

#### Scenario: 欠落があれば素材IDと名前を警告に出す
- **WHEN** 周回対象素材のいずれかが items に無い、または正のドロップ率が無い状態で更新ジョブが走ったとき
- **THEN** 更新ジョブのログに、該当素材の Atlas ID・名前・欠け方を含む警告が出る。
- **THEN** 他の検証が通っていれば、`all_drops_json` は通常どおり書き込まれる。

#### Scenario: 欠落が無ければ警告を出さない
- **WHEN** 周回対象素材がすべて items にあり、それぞれ正のドロップ率を持つとき
- **THEN** 欠落の警告は出ない。
