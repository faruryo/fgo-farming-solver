# Proposal

## Why

計算履歴はログインユーザーの D1 に保存される機能だが、未ログインでもナビ・周回結果画面・ダッシュボードに「計算履歴」への導線が出て、開くと空表示になる。さらに未ログインでも計算履歴の取得と計算後のスナップショット保存が送信され、401 が返って処理が止まったように見える（#74）。

## What Changes

- 未ログインのときは、ナビゲーション・周回結果画面・ダッシュボードの「計算履歴」への導線と、計算履歴の推移グラフを出さない
- 未ログインで計算履歴ページを直接開いたときは、計算履歴を取得せず、ログインを案内してログイン画面（`/cloud`）への導線を出す
- 未ログインのときは、計算履歴の取得（推移グラフ・ダッシュボードの直近の結果・履歴ページ）と、ソルバー実行後のスナップショット保存を送信しない
- ログイン状態の確認中は、計算履歴を取得せず導線も出さない（確認が終わってから決める）

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `farming-history`: 未ログイン時の計算履歴の導線と取得の扱いを追加する
- `sync`: ソルバー実行時のスナップショット保存を、ログインユーザーに限る

## Impact

- 対象のコード: ナビゲーション、周回結果画面、ダッシュボード（計算履歴へのリンク・推移グラフ・直近の結果の取得）、計算履歴ページ、ソルバー実行後のスナップショット保存
- API とデータ: 変更しない（未ログインに 401 を返す API はそのまま）
- ログインユーザーの表示と動作は変わらない
