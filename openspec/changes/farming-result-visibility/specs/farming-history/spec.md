# Spec Delta: farming-history

## ADDED Requirements

### Requirement: 計算結果の公開・非公開設定
システムは、周回計算結果の公開・非公開（`is_public`）をユーザーごとに選択・管理できる手段を提供しなければならない (SHALL)。

#### Scenario: ログインユーザーの新規結果保存時の既定値適用
- **WHEN** ログインユーザーが周回計算を実行して結果を保存するとき
- **THEN** ユーザーの端末設定（localStorage）で選択された既定の公開設定（公開または非公開）に従って保存される。端末設定の初期値は「公開」とする。

#### Scenario: 未ログインユーザーの結果保存
- **WHEN** 未ログインユーザーが周回計算を実行して結果を保存するとき
- **THEN** 結果は常に「公開」として保存される。

#### Scenario: 未ログインユーザーによる非公開計算要求の拒絶（fail-closed）
- **WHEN** 未ログインユーザーが非公開設定（`isPublic=false`）を指定して周回計算 API を呼び出したとき
- **THEN** 401 Unauthorized エラーを返却して公開保存されるのを防止する。

#### Scenario: 認証状態読み込み中の周回計算送信抑止
- **WHEN** セッション認証状態の判定中（loading）であるとき
- **THEN** 周回計算の送信は抑止され、認証確定後に認証状態に応じた公開設定（未ログイン時は常に公開、ログイン時は端末設定値）で送信される。

#### Scenario: 2目標ペア保存時の公開設定連動
- **WHEN** 2目標（必要分/ストック込み）の計算結果（同一 `batch_id` を持つペア）を保存するとき
- **THEN** 目標A行・目標B行の両方に同一の公開設定が適用されて保存される。

#### Scenario: 結果画面での所有者による公開・非公開切り替え
- **WHEN** ログインユーザーが自身が所有する結果のページ（`/farming/results/[id]`）を開いたとき
- **THEN** 公開・非公開を切り替えるスイッチが表示され、操作によって結果の公開状態が即座に更新される。
- **WHEN** 切り替え対象の結果が `batch_id` を持つペアであるとき
- **THEN** 同一 `batch_id` を持つ両方の行の公開状態が連動して更新される。

#### Scenario: 所有者以外の結果画面での切り替え非表示
- **WHEN** 未ログインユーザーまたは所有者以外のユーザーが公開された結果のページを開いたとき
- **THEN** 公開・非公開を切り替えるスイッチは表示されない。

#### Scenario: 論理削除済みの結果における所有者の公開設定切り替え
- **WHEN** 計算履歴から論理削除された結果のページを所有者が開いて公開設定を切り替えたとき
- **THEN** 正常に公開・非公開が更新され、非公開に設定された場合は即座に第三者から閲覧不可となる。

#### Scenario: 公開結果でのツイートボタン表示
- **WHEN** 結果が公開状態（`is_public = 1`）であるとき
- **THEN** 結果画面にツイートボタンが表示され、共有が可能である。

#### Scenario: 非公開結果でのツイートボタン非表示
- **WHEN** 結果が非公開状態（`is_public = 0`）であるとき
- **THEN** 結果画面にツイートボタンは表示されない。

### Requirement: 計算結果の閲覧アクセス制御
システムは、非公開に設定された計算結果へのアクセスを所有者本人のみに制限しなければならない (SHALL)。

#### Scenario: 公開結果の閲覧
- **WHEN** 公開状態（`is_public = 1`）の結果ページ URL（`/farming/results/[id]`）にアクセスしたとき
- **THEN** ログインの有無やユーザーによらず、誰でも結果を閲覧できる。

#### Scenario: 所有者による非公開結果の閲覧
- **WHEN** 非公開状態（`is_public = 0`）の結果の所有者（ログイン中本人）が該当ページ URL にアクセスしたとき
- **THEN** 結果ページが正常に表示される。

#### Scenario: 所有者以外による非公開結果へのアクセス拒否
- **WHEN** 未ログインユーザーまたは所有者以外のログインユーザーが非公開状態（`is_public = 0`）の結果ページ URL にアクセスしたとき
- **THEN** 結果が存在しない場合と同様に 404（Not Found）が返される。

#### Scenario: 既存データの公開維持（後方互換）
- **WHEN** 本機能導入前に保存された既存の計算結果（`is_public` カラムがマイグレーション時の既定値 1 または NULL 扱い）にアクセスしたとき
- **THEN** 公開状態として扱われ、共有済みリンクは引き続き誰でも閲覧できる。
