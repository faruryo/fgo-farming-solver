## MODIFIED Requirements

### Requirement: イベント食材所持数の入力と料理作成最適化 (Event Craft Optimization)
システムは、イベント食材（うちなー海鮮盛り、うちなーお肉盛り、うちなー野菜盛り）の所持数を入力し、ユーザーの素材不足状況とフリクエ周回効率に基づいて混合整数線形計画法（MILP）により最適な料理作成配分を計算・提示しなければならない (SHALL)。料理1皿あたりの素材獲得は確定1個ではなく、検証に基づく期待値で評価しなければならない (SHALL)。期待高の素材は 40%、同じレアリティ帯の残り枠（他の対象素材およびQPまたは種火）は均等とする。QPおよび種火は育成不足の充足に使ってはならない (SHALL)。同一レアリティの他の料理対象素材には、残り枠の均等分を期待獲得として加算しなければならない (SHALL)。

#### Scenario: 食材数の入力と最適化計算
- **WHEN** ユーザーが各食材の所持数を入力したとき
- **THEN** フリクエ周回とクラフト作成を同時に最適化する混合整数線形計画法（MILP）により、手持ち食材の制約内で残余周回コストが最小（総削減コストが最大）となる料理作成数の組み合わせが即座に算出される。
- **THEN** 各料理の作成推奨数、期待高の素材名、消費する食材数が表示される。
- **THEN** 不足枠での作成には「削減AP」または「削減周回数」が表示され、余剰枠での作成には「獲得価値（期待獲得の単体AP/周回換算）」として区別して表示される。
- **THEN** 各料理カードの不足枠削減量は、その料理の作成をゼロにしたときの残余周回コスト差である。再計算の need はクランプ後の残不足に期待獲得を足し戻すのではなく、元の不足から当該以外の料理の期待獲得を引いた値とする。整数皿が期待不足を超えても、カード削減は元の不足を超える獲得として計上されない。
- **THEN** おすすめ配分（各料理の作成数）に加え、その皿数を実行したときの育成素材ごとの期待獲得個数の合計が表示される。値は各料理の作成数×当該素材の期待 yield の和である。QPおよび種火は収集数に含めない。
- **THEN** 作成後に余る各食材の残数が表示される。

#### Scenario: 期待値による同レア素材の同時充足
- **WHEN** 同じレアリティ帯に複数の不足素材があり、ある料理の期待高がそのうち1種であるとき
- **THEN** その料理の作成は期待高素材だけでなく、同帯の他の対象素材の期待獲得も不足充足に算入される。
- **THEN** 銅・銀では期待高 0.40・他対象素材各 0.15、金では期待高 0.40・他対象素材各 0.12 として評価される。

#### Scenario: 主産物不足を超える作成でついでを充足する
- **WHEN** ある料理の期待高素材の不足は小さいが、同レアの他対象素材の不足が大きいとき
- **THEN** システムは期待高素材の不足個数を作成皿数の上限にしてはならない。
- **THEN** 残余周回コストを減らす範囲で、ついで期待値が効く皿数を作成してよい。

#### Scenario: AP節約優先と周回数節約優先の適用
- **WHEN** 最適化モードが「AP節約優先」のとき
- **THEN** フリクエ周回の総消費APを目的関数として直接最小化し、総AP削減量が最大となる料理作成配分を算出する。
- **WHEN** 最適化モードが「周回数節約優先」のとき
- **THEN** フリクエ周回の総周回数を目的関数として直接最小化し、総周回削減数が最大となる料理作成配分を算出する。

#### Scenario: マシュによるクラフトアドバイス表示
- **WHEN** 料理作成の最適配分が算出されたとき
- **THEN** マシュのセリフ枠に、最も効果の高い料理名や合計削減コスト（APまたは周回数）を含む具体的なアドバイス文章が表示される。

### Requirement: 食材使い切りオプション (Exhaust Ingredients Option)
システムは、不足素材の期待充足を超えて余った食材を期待獲得価値の高い料理で使い切るかどうかを制御する「食材を使い切る」オプションを提供しなければならない (SHALL)。

#### Scenario: 食材使い切りが有効な場合
- **WHEN** 「食材を使い切る」が有効（ON）のとき
- **THEN** 不足素材の期待充足後（または不足がない場合）でも、食材が残っている限り、期待獲得バスケットの単体AP/周回価値が最も高い料理を作成して食材余剰を最小化する。
- **THEN** 余剰枠で作成された料理の効果は「削減量」ではなく「獲得価値（単体AP/周回換算）」として明示される。

#### Scenario: 食材使い切りが無効な場合
- **WHEN** 「食材を使い切る」が無効（OFF）のとき
- **THEN** 周回コスト削減効果がこれ以上増えない皿は作らず、また周回コスト削減効果が 0 の作成（他の不足素材集めのついでに揃う期待獲得など）には食材を使わず、真に周回を削減できる分を満たした時点で食材の消費を停止する。
