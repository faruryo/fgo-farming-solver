## ADDED Requirements

### Requirement: 育成ぶんの必要数を同期しない
システムは、育成ぶんの必要数の保存先をクラウド同期の対象に含めてはならない (SHALL NOT)。育成ぶんは、同期されるサーヴァントの状態から各端末で求め直す。旧 `material/result` は、移行前のデータを読み替えるために同期対象に残さなければならない (SHALL)。

#### Scenario: 育成ぶんの書き直しは同期の変更を作らない
- **WHEN** 育成ぶんの必要数が書き直されたとき
- **THEN** クラウド同期の未保存の変更は作られず、`/api/cloud` へ育成ぶんは送られない

#### Scenario: 別の端末での復元
- **WHEN** 別の認証済み端末で同期を実行し、サーヴァントの状態が復元されたとき
- **THEN** その端末の育成ぶんは復元したサーヴァントの状態から求め直され、必要数はクラススコアぶんと合算した値になる
