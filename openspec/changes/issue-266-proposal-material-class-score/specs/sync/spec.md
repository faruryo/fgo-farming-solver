## ADDED Requirements

### Requirement: 育成ぶんの必要数のクラウド同期
システムは、育成ぶんの必要数の保存先をクラウド同期の対象に含め、状態スナップショットにも保存しなければならない (SHALL)。旧 `material/result` は、移行前のデータを読み替えるために同期対象に残さなければならない (SHALL)。進捗の比較は、スナップショットごとに育成ぶんとクラススコアの状態から必要数を求め、育成ぶんが無いスナップショットでは旧 `material/result` の値を必要数として使わなければならない (SHALL)。

#### Scenario: 育成ぶんのクラウド保存と復元
- **WHEN** 育成ぶんの必要数が書き直され、オートシンクが有効であるとき
- **THEN** 他の同期対象と同じ間隔で `/api/cloud` を通じて保存される
- **WHEN** 別の認証済み端末で同期を実行したとき
- **THEN** 保存された育成ぶんの必要数が復元され、その端末の必要数はクラススコアぶんと合算した値になる

#### Scenario: 移行前のスナップショットとの比較
- **GIVEN** 過去のスナップショットに育成ぶんが無く、旧 `material/result` だけがある
- **WHEN** 進捗レポートが過去と現在の必要数を比べるとき
- **THEN** 過去の必要数は旧 `material/result` の値で、現在の必要数は育成ぶんとクラススコアぶんの合算で求められ、クラススコアぶんが二重に数えられない
