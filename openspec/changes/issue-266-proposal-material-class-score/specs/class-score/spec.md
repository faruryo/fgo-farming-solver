## MODIFIED Requirements

### Requirement: クラススコア目標ステータスの管理
システムは、全9クラス（セイバー、アーチャー、ランサー、ライダー、キャスター、アサシン、バーサーカー、EX1、EX2）それぞれについて、クラススコアの目標ステータス（未設定 `none`、目標 `target`、解放済み `completed`）を管理し、ローカルストレージへ永続化しなければならない (SHALL)。盤面に未解放の目標マスが1つ以上あるクラスは、全マスが目標でなくても `target` として扱わなければならない (SHALL)。

#### Scenario: クラスごとの目標ステータス切替
- **WHEN** ユーザーが特定クラスのカード上で「目標にする」を選択したとき
- **THEN** そのクラスのステータスが `target` に更新され、必要素材集計の対象に含まれる。
- **THEN** 変更内容は `localStorage` の `classScore` キーへ保存され、`ls-sync` イベントが発火する。

#### Scenario: 解放済みへのステータス変更
- **WHEN** ユーザーが特定クラスのカード上で「解放済み」を選択したとき
- **THEN** そのクラスのステータスが `completed` に更新され、必要素材集計からは除外される。

#### Scenario: 未設定へのリセット
- **WHEN** ユーザーが特定クラスのカード上で「未設定」を選択したとき
- **THEN** そのクラスのステータスが `none` に戻り、必要素材集計から除外される。

#### Scenario: 一部のマスだけを目標にしたクラス
- **GIVEN** セイバーの盤面で一部のルートのマスだけが「目標」で、ほかのマスは未設定である
- **WHEN** ユーザーが `/material/class-score` の一覧を開いたとき
- **THEN** 一覧の目標クラス数は「目標: 1 / 9」になり、必要素材サマリーが表示される
- **THEN** セイバーのカードの未設定 / 目標 / 解放済 の切り替えは「目標」が選ばれた表示になり、「未設定」が選ばれた表示にはならない

#### Scenario: 目標マスがすべて解放済になったクラス
- **GIVEN** あるクラスの目標マスがすべて解放済で、未解放の目標マスが残っていない
- **WHEN** 一覧の集計が求められるとき
- **THEN** 全マスが解放済なら `completed`、そうでなければ `none` として扱われ、目標クラス数に数えられない

### Requirement: クラススコア必要素材の算出
システムは、`target` のクラスについて、盤面の目標マスのうち未解放のマスに必要な素材（通常強化素材、ピース、モニュメント、QP、星光の砂、新星/明星/極星のトーチ）を集計しなければならない (SHALL)。全マスが目標のクラスでは、その値は最大解放に必要な素材から解放済のマスのぶんを除いた値に等しい。

#### Scenario: 単一クラスの必要素材算出
- **GIVEN** セイバークラスのみが、解放済のマスなしで全マスを目標に設定されている
- **WHEN** 必要素材が集計されるとき
- **THEN** QP 3億1,700万、セイバーピース 140個、セイバーモニュメント 500個、通常素材（英雄の証 70個、竜の牙 70個等）、星光の砂 6,680個、新星のトーチ 4個、明星のトーチ 4個、極星のトーチ 2個が算出される。

#### Scenario: 複数クラスの必要素材合算
- **GIVEN** セイバーとバーサーカーが `target` に設定されている
- **WHEN** 必要素材が集計されるとき
- **THEN** 両クラスで共通して要求される素材（虚影の塵など）やQP・星光の砂・トーチは合算され、各クラス固有のピース・モニュメントはそれぞれの必要数が計上される。

#### Scenario: 一部だけ目標のクラスの必要素材
- **GIVEN** セイバーの盤面で一部のマスだけが目標である
- **WHEN** 必要素材が集計されるとき
- **THEN** 目標かつ未解放のマスに必要な素材だけが計上され、目標でないマスのぶんは含まれない

### Requirement: 起点からのルート一括設定（目標・解放済のデフォルト化）
システムは、クラスボード上の任意のマスの状態変更において、起点からそのマスに至る最短経路上の全マスを一括して「目標」または「解放済」に設定する動作をデフォルトとして提供しなければならない (SHALL)。また、必要に応じて単一マスのみの状態変更を行うオプションも提供しなければならない (SHALL)。経路上の「解放済」のマスを「目標」に戻す一括操作も提供しなければならない (SHALL)。

#### Scenario: ルート一括目標選択（デフォルト）
- **WHEN** ユーザーが詳細ダイアログで「ルート目標」を選択したとき
- **THEN** 起点から対象マスまでの最短経路（接続ラインで繋がれたノード列）が自動探索され、経路上の未解放マスがすべて「目標」に一括設定される。
- **THEN** 既に「解放済」に設定されているマスは解放済みのまま維持される。

#### Scenario: ルート一括で解放済を目標に戻す
- **GIVEN** 起点から対象マスまでの経路上に「解放済」のマスがある
- **WHEN** ユーザーが詳細ダイアログで経路を目標に戻す操作を選択したとき
- **THEN** 経路上の実サインマスはすべて「目標」になり、「解放済」から外れる
- **THEN** 経路の外のマスの状態は変わらない

#### Scenario: ルート一括解放済選択（デフォルト）
- **WHEN** ユーザーが詳細ダイアログで「ルート解放済」を選択したとき
- **THEN** 起点から対象マスまでの最短経路上の全マスが「解放済」に一括設定される。
- **THEN** 経路上のマスが「目標」に含まれていた場合は目標から除外される。

#### Scenario: 単体マス操作オプション
- **WHEN** ユーザーが詳細ダイアログの「単体操作」で特定マスのみを目標または解放済にしたとき
- **THEN** 起点からの経路には影響を与えず、対象マスのみの状態が指定の状態に変更される。

#### Scenario: 未解放時の起点と反対側（下流ノード）一括未解放
- **WHEN** ユーザーがマスを「未解放」に設定したとき
- **THEN** 起点マスから対象マスを経由しないと到達できない、起点と反対側（下流/外側）の全マスが一括して「未解放」に更新される。
- **THEN** 起点から別経路で到達可能なマスは維持される。

## ADDED Requirements

### Requirement: クラスカードの必要素材表示
システムは、クラススコア一覧の各クラスカードに、そのクラスの状態に応じた必要素材・QP を表示しなければならない (SHALL)。`target` のクラスでは目標かつ未解放のマスぶんを表示し、`target` の全カードの値の合計は一覧の必要素材サマリーと一致しなければならない (SHALL)。`none` のクラスでは全マス解放に必要な数を、目標ぶんとは区別できる見出しで表示しなければならない (SHALL)。

#### Scenario: 一部だけ目標のクラスのカード
- **GIVEN** セイバーの盤面で一部のマスだけが目標である
- **WHEN** ユーザーが一覧を開いたとき
- **THEN** セイバーのカードの必要QPと素材は、目標かつ未解放のマスぶんの値で表示され、全マス合計の固定値は表示されない

#### Scenario: カードの合計とサマリーの一致
- **GIVEN** 複数のクラスが `target` である
- **WHEN** ユーザーが一覧を開いたとき
- **THEN** `target` の各カードの必要QPを足した値は、必要素材サマリーの必要QPと等しい

#### Scenario: 未設定のクラスのカード
- **GIVEN** アーチャーに目標マスも解放済のマスもない
- **WHEN** ユーザーが一覧を開いたとき
- **THEN** アーチャーのカードには、全マス解放に必要な数であることが分かる見出しとともに必要QPと素材が表示され、目標のカードの「目標ぶん」と同じ見出しにはならない
