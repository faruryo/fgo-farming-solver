## ADDED Requirements

### Requirement: 品目の欲しい・いらないの設定のクラウド同期
システムは、品目ごとの「欲しい／いらない」の設定（`item-want-setting`）をクラウド同期の対象に含め、複数端末間で同期しなければならない (SHALL)。交換所の交換回数・所持数・ボーナスなどイベントごとの入力は、今までどおりクラウド同期の対象に含めてはならない (SHALL NOT)。

#### Scenario: 設定のクラウド保存と復元
- **WHEN** 利用者がアイテム一覧で聖杯を「いらない」にし、オートシンクが有効であるとき
- **THEN** 変更から 5 秒後に `/api/cloud` を通じて Cloudflare KV に設定が保存される
- **WHEN** 別の認証済み端末でログインまたは同期を実行し、聖杯を並べる交換所を開いたとき
- **THEN** 聖杯は「いらない」になっていて、表の最後の「いらない品目」に畳まれている

#### Scenario: 交換回数は同期しない
- **WHEN** 利用者がある端末の交換所で呼符に 3 回を入れ、別の認証済み端末で同期を実行して同じ交換所を開いたとき
- **THEN** 別の端末の呼符の交換回数は、その端末で入れた回数（入れていなければ 0）のままである
