## MODIFIED Requirements

### Requirement: まとめて置き換える操作の結果を保存する
システムは、「全部交換」と「不足素材のみ」の操作で交換回数をまとめて置き換えたときも、今までどおり交換回数を置き換え、置き換えた後の交換回数をそのイベントの保存値にしなければならない (SHALL)。どちらの操作も「いらない」の品目（`item-want-setting`）の保存した交換回数を変えてはならない (SHALL NOT)。操作の後に利用者が個別に変えた回数も、同じく保存しなければならない (SHALL)。

#### Scenario: 全部交換の後に開き直す
- **WHEN** 利用者が「全部交換」を押してから、ページを読み込み直したとき
- **THEN** 在庫上限のある「欲しい」の品目の交換回数は在庫上限の回数のままで、在庫上限の無い品目と「いらない」の品目は操作の前の回数のままになっている

#### Scenario: 不足素材のみの後に開き直す
- **WHEN** 利用者が「不足素材のみ」の操作をして、ある品目の交換回数が 5 になってから、ページを読み込み直したとき
- **THEN** その品目の交換回数は 5 のままで、ほかの品目も操作の後の回数のままになっている

### Requirement: 保存値を読むまで初期値を見せない
システムは、ロトの無い交換所イベントの交換所の画面で、端末の保存値から出す表示を、その保存値を読み終えるまで初期値（0、空、既定の選択）で表示してはならず (SHALL NOT)、読み込み中であることが分かる表示にしなければならない (SHALL)。対象は、周回計算の欄（交換回数・所持数・ボーナス・ボーナス礼装の ☆ ごとの入力・フレンドの礼装・比較の表で選んだ行）とそこから出す必要量・周回の内訳・合計・ボーナス礼装の比較、品目の「欲しい／いらない」の設定（`item-want-setting`。「いらない」の行を一覧から外して畳むことを含む）、育成計画と所持数から出す品目の状態、AP 予算のマスターレベル・黄金の果実の所持数とそこから出す内訳とする。保存値を読み終えたら、保存値（保存値の無い欄は今までどおりの初期値）で表示しなければならない (SHALL)。読み込み中は、利用者が欄を変えられてはならない (SHALL NOT)。保存値を読むことで端末に書き込んではならず (SHALL NOT)、「開いただけでは書き込まない」の決まりは読み込み中の表示があっても変わらない。サーヴァント扱いの品目だけの交換所の一覧のように、端末の保存値から出す表示の無い部分は、読み込みを待たずに表示してよい。

#### Scenario: 読み込み直しても 0 が見えない
- **WHEN** 利用者が 80632 の交換所で、ある品目の交換回数に 3、ある通貨の所持数に 200、その通貨のボーナスに 2 を入れてから、ページを読み込み直したとき
- **THEN** 保存値を読み終えるまで、その品目の交換回数・その通貨の所持数・ボーナス・必要量・周回の内訳は 0 として表示されず、読み込み中の表示になる
- **THEN** 保存値を読み終えると、交換回数は 3、所持数は 200、ボーナスは 2 で表示され、必要量と周回の内訳はそれらの値で表示される

#### Scenario: 保存値の無い端末
- **WHEN** 利用者が一度も値を入れたことのないイベントの交換所を開いたとき
- **THEN** 保存値を読み終えるまでは読み込み中の表示になり、読み終えると交換回数・所持数・ボーナスは 0 で表示される
- **THEN** そのイベントの交換所の入力は端末に書き込まれていない

#### Scenario: 育成計画と AP 予算も初期値を見せない
- **WHEN** 育成計画を設定し、マスターレベルと黄金の果実の所持数を入れたことのある利用者が、交換所のページを読み込み直したとき
- **THEN** 保存値を読み終えるまで、「育成対象を設定すると…」の未設定の案内、既定のマスターレベル、黄金の果実の 0 は表示されず、読み込み中の表示になる
- **THEN** 保存値を読み終えると、育成計画から出す品目の状態と、入れたマスターレベル・黄金の果実の所持数で表示される

#### Scenario: 読み込み中は入力で保存値を上書きしない
- **WHEN** 交換所の保存値を読み終える前に、利用者が交換所を操作しようとしたとき
- **THEN** 交換回数・所持数・ボーナスの欄は変えられず、保存値は読み込み前の値のまま残り、読み終えると保存値で表示される

#### Scenario: いらない品目を読み込み前に見せない
- **WHEN** 聖杯を「いらない」にしている利用者が、交換所のページを読み込み直したとき
- **THEN** 設定を読み終えるまで、聖杯の行が入力欄つきで一覧に出ることはなく、読み終えると聖杯は表の最後の「いらない品目」に畳まれている
