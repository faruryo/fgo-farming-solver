## ADDED Requirements

### Requirement: 箱計画のボーナスの入力
システムは、箱のあるイベントの箱計画の入力の欄に、箱を開ける通貨と、交換所の対価の通貨（箱を開ける通貨と同じものは1つにまとめる）のそれぞれの「1ドロップにつき +N」を入れる欄を設けなければならない (SHALL)。欄の見出し・説明の1行・値の扱い（0 以上の整数、初期値 0、負の数・小数・数でない値は 0 以上の整数に直す）は、交換所のボーナスの入力と同じでなければならない (SHALL)。入れた値は、交換所のボーナスと同じく画面を開いている間だけ持ち、保存してはならない (SHALL NOT)。礼装の所持を入れる欄を設けてはならない (SHALL NOT)。周回クエストにドロップの統計が無く、1周あたりの獲得数を手で入れるときは、ボーナスの欄を出してはならない (SHALL NOT)。

#### Scenario: 箱の通貨と交換所の通貨の欄
- **WHEN** 箱を開ける通貨が1種類、交換所の対価の通貨が4種類あり、ドロップの統計がある箱のイベントを開いたとき
- **THEN** 箱計画の入力の欄に、5種類の通貨のそれぞれに初期値 0 のボーナスの欄が、「ドロップ増加礼装」の見出しと説明の1行とともに表示される

#### Scenario: 不正な値
- **WHEN** 利用者が箱計画のボーナスの欄に -3 や 2.5 を入れたとき
- **THEN** 値はそれぞれ 0 と 2 として扱われる

#### Scenario: 1周の獲得数を手で入れる箱計画
- **WHEN** 周回クエストにドロップの統計が無い箱のイベントを開いたとき
- **THEN** ボーナスの欄は表示されず、1周あたりの獲得数を手で入れる欄だけが表示される

#### Scenario: 画面を開き直したとき
- **WHEN** 利用者が箱計画のボーナスに 2 を入れたあと、ページを読み込み直したとき
- **THEN** ボーナスの欄は 0 に戻る

### Requirement: 箱計画の周回の計算への反映
システムは、箱計画の周回の計算（箱を開けるのに要る周回数、クエストごとの周回数、合計 AP、AP 予算）を、各ドロップの1周の獲得量を「素の1周の期待値 + 1周あたりのドロップ回数 × その品目のボーナス」にした値で求めなければならない (SHALL)。入力モード（育成ロスター・箱数・欲しいアイテム）によらず、同じボーナス込みの値で求めなければならない (SHALL)。すべてのボーナスが 0 のときは、ボーナスの機能が無いときと同じ結果を出さなければならない (SHALL)。ボーナスを1つでも入れたときは、計算結果の近くに、入れたドロップ増加礼装のボーナス（1ドロップにつき +N）を足して計算していることを示さなければならない (SHALL)。1周あたりのドロップ回数を持たないドロップにはボーナスを足してはならず (SHALL NOT)、ボーナスが入っていて、その品目にドロップ回数を持たないドロップが1つでもあるときは、ボーナスを反映できない品目があることを表示しなければならない (SHALL)。

#### Scenario: ボーナスで周回数が減る
- **WHEN** 箱を開けるのに要る通貨が 300 で、その通貨を落とすクエストが1つだけ（素の1周の期待値 10.0、1周あたりのドロップ回数 5.0）あり、利用者がその通貨のボーナスに 2 を入れたとき
- **THEN** 1周の獲得量は 20.0 として解かれ、そのクエストの周回数は 15 周になり、合計 AP と AP 予算は 15 周の分になる

#### Scenario: ボーナスが0のとき
- **WHEN** すべてのボーナスが 0 のとき
- **THEN** 箱計画の周回数・合計 AP・AP 予算は、ボーナスの機能が無いときと同じである

#### Scenario: 入力モードを切り替えたとき
- **WHEN** 利用者がボーナスを入れたまま、入力モードを箱数から欲しいアイテムに切り替えたとき
- **THEN** ボーナスの値は保たれ、切り替えた先の周回の計算もボーナス込みの値で求められる

#### Scenario: 注記
- **WHEN** 利用者が箱計画のボーナスを1つでも 1 以上にしたとき
- **THEN** 計算結果の近くに、入れたドロップ増加礼装のボーナスを足して計算していることが表示される

#### Scenario: 取り込み直す前のデータ
- **WHEN** ドロップがどれも1周あたりのドロップ回数を持たない箱のイベントで、利用者が箱を開ける通貨のボーナスに 2 を入れたとき
- **THEN** 箱計画の周回数は素の値のまま出て、その通貨にボーナスを反映できないことが表示される
