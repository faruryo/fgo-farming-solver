# Proposal

## Why

伝承結晶は育成計画で扱う素材なので、計画で使わないときは「使わない」になり、不足素材のみの操作では交換回数が 0 のままになる。「必要」と「不要」の切り替えも計画の対象外の品目にしか出ないので、利用者が選んで入れることもできない。カルデアの夢火は計画の対象外なので切り替えは出るが、初期値が「不要」なので、選ばないと入らない。どちらも計画で使わなくても交換所で取り逃したくない人が多い品目なので、オーナーの判断（#208、2026-11-02）として、この2つは既定で在庫上限まで交換に入れる。ただし要らない人もいるので、品目ごとにオフにできるようにする。

## What Changes

- 既定で交換する品目として、伝承結晶（Atlas 6999）とカルデアの夢火（Atlas 1000）の2つを決める。コード・リムーバー／オープナーやサーヴァントコインは入れず、今までどおり計画の対象外で、初期値は「不要」
- この2つには、判定が「使わない」「足りている（交換不要）」「あと N 個」のときも「必要」と「不要」の切り替えを出し、まだ選んでいないときの初期値を「必要」にする（夢火は計画の対象外なので、切り替えは今までも出ていて、初期値だけが変わる）
- 選んだ内容は、計画の対象外の品目の切り替えと同じく品目ごとに端末に保存し、別のイベントでも同じ選択を使う
- 「必要」のとき、不足素材のみの操作では、在庫上限のある品目なら不足の有無や量に関わらず在庫上限の回数にする。在庫上限の無い品目は、不足が残っていれば不足の分、残っていなければ 0 にして回数を手で入れるよう示す
- 「不要」にしたときは、今までどおり育成計画の不足の分だけ入れる（不足が無ければ 0）
- 表示のラベルは今までどおり（不足があれば「あと N 個」、無ければ「足りている（交換不要）」「使わない」「計画の対象外」）
- 育成計画で扱う素材の一覧を読み込めないときも、この2つは番号で分かるので、伝承結晶は育成計画で扱う素材、夢火は計画の対象外として扱い、ラベルと切り替えを出す

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `event-shop-roster-need`: 品目ごとの要る・要らないの表示、計画の対象外の品目の切り替え、不足素材のみの操作の回数の入れ方に、既定で交換する2つの品目の扱いを足す

## Impact

- 交換所の一覧の品目の状態と、不足素材のみの割り当て（`lib/event-shop-summary.ts`、`components/events/EventShopList.tsx`）
- 端末に保存する「要る」の値（`STORAGE_KEYS.EVENTS_SHOP_WANTED_ITEMS`）に、既定で交換する品目の「不要」を `false` として持たせる。今までの保存値（`true` だけ）はそのまま読める
- API・データの取得・表示の文言は変えない
