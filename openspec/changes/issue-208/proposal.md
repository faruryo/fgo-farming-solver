# Proposal

## Why

伝承結晶は育成計画で扱う素材なので、計画で使わないときは「使わない」になり、不足素材のみの操作では交換回数が 0 のままになる。「必要」と「不要」の切り替えも計画の対象外の品目にしか出ないので、利用者が選んで入れることもできない。伝承結晶は計画で使わなくても交換所で取り逃したくない品目なので、オーナーの判断（#208）として、不足素材のみでいつも在庫上限まで交換に入れる。

## What Changes

- 不足素材のみの操作で、伝承結晶の品目は、育成計画での不足の有無に関わらず、在庫上限のある品目なら在庫上限の回数にする
- 在庫上限の無い伝承結晶の品目は、不足があればこれまでどおり不足の分を入れ、不足が無ければ「必要」を選んだ在庫上限の無い計画の対象外の品目と同じく 0 にして、回数を手で入れるよう示す
- 伝承結晶に不足があるときは、これまでどおり「あと N 個」と表示し、在庫上限まで交換しても残る不足は「交換所では N 個足りない」と表示する
- 伝承結晶に不足が無いとき（足りている・使わない）は、「足りている（交換不要）」「使わない」に代えて「いつも上限まで交換」と表示し、交換の要らない品目として目立たなくしない
- 「必要」と「不要」の切り替えは足さない

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `event-shop-roster-need`: 品目ごとの要る・要らないの表示と、不足素材のみの操作の回数の入れ方に、伝承結晶の扱いを足す

## Impact

- 交換所の一覧の品目の状態と、不足素材のみの割り当て（`lib/event-shop-summary.ts`、`components/events/EventShopList.tsx`）
- 表示の文言（`locales/` の ja と en）
- 端末に保存する値・API・データの取得は変えない
