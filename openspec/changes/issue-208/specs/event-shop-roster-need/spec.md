# Spec Delta

## MODIFIED Requirements

### Requirement: 品目ごとの要る・要らない
システムは、ロトの無い交換所イベントの交換所の品目を、このサイトの育成計画で扱う素材（育成計画が必要数を出しうる素材。QP を除く）と、それ以外の品目に分け、品目ごとに次のどれかを表示しなければならない (SHALL)。育成計画で扱う素材は、育成計画の必要数から所持数を引いた不足（0 未満は 0）を求め、必要数が 1 以上で不足が 0 なら「足りている（交換不要）」、不足が 1 以上なら「あと N 個」（N は不足）、必要数が 0 なら「使わない」と表示する。ただし伝承結晶の品目は、不足が 0 のとき（足りている・使わない）は「足りている（交換不要）」「使わない」に代えて「いつも上限まで交換」と表示し、交換の要らない品目として目立たなくしてはならない (SHALL NOT)。不足が 1 以上の伝承結晶は、ほかの素材と同じく「あと N 個」と表示する。育成計画で扱わない品目（呼符・サーヴァントコイン・聖杯・コード・リムーバー・他のイベントアイテムなど）は「計画の対象外」と表示する。育成計画で扱う素材の一覧を読み込めないときは、必要数が 0 の品目にラベルと切り替えを表示せず、計画の対象外の品目を見分けられないことを表示しなければならない (SHALL)。QP の品目は対象に含めず、ラベルを表示しない。不足は品目が得る素材ごとに求め、交換所に同じ素材の品目が複数あっても同じ不足を表示する。育成計画と所持数は、育成計画のページと所持数のページで保存した値を読むだけとし、交換所の画面から書き換えてはならない (SHALL NOT)。

#### Scenario: 不足がある素材
- **WHEN** 育成計画で素材 S の必要数が 30、所持数が 25 のとき
- **THEN** 素材 S の品目に「あと 5 個」と表示される

#### Scenario: 足りている素材
- **WHEN** 育成計画で素材 S の必要数が 30、所持数が 40 のとき
- **THEN** 素材 S の品目に「足りている（交換不要）」と表示される

#### Scenario: 育成計画で扱うが必要数が 0 の素材
- **WHEN** 品目が育成計画で扱う素材で、育成計画での必要数が 0 のとき
- **THEN** その品目に「使わない」と表示される

#### Scenario: 育成計画で扱わない品目
- **WHEN** 品目が呼符・コード・リムーバー・他のイベントアイテムのどれかのとき
- **THEN** その品目に「計画の対象外」と表示される

#### Scenario: 育成計画で扱う素材の一覧を読み込めないとき
- **WHEN** 育成計画は読み込めたが、育成計画で扱う素材の一覧を読み込めなかったとき
- **THEN** 不足のある素材と足りている素材にはラベルが表示され、必要数が 0 の品目にはラベルと切り替えが表示されず、計画の対象外の品目を見分けられないことが表示される

#### Scenario: 育成計画で使わない伝承結晶
- **WHEN** 伝承結晶の育成計画での必要数が 0 のとき
- **THEN** 伝承結晶の品目に「使わない」ではなく「いつも上限まで交換」と表示され、「必要」と「不要」の切り替えは表示されない

#### Scenario: 足りている伝承結晶
- **WHEN** 伝承結晶の育成計画での必要数が 2、所持数が 5 のとき
- **THEN** 伝承結晶の品目に「足りている（交換不要）」ではなく「いつも上限まで交換」と表示される

#### Scenario: 不足のある伝承結晶
- **WHEN** 伝承結晶の育成計画での必要数が 5、所持数が 2 のとき
- **THEN** 伝承結晶の品目に「あと 3 個」と表示される

### Requirement: 不足素材のみ
システムは、交換所の周回計算に「不足素材のみ」の操作を設けなければならない (SHALL)。操作をすると、すべての品目の交換回数を次のとおりに置き換える。不足のある素材について、交換所の元の順に品目を見て、まだ埋まっていない不足を「1回の交換で得る個数」で割って切り上げた回数を、在庫上限のある品目では在庫上限までで入れ、入れた回数で得る個数を不足から差し引いて次の品目へ進む。在庫上限の無い品目は上限で打ち切らない。伝承結晶の品目は、不足の有無に関わらず、在庫上限のある品目なら在庫上限の回数にし、入れた回数で得る個数を伝承結晶の不足から差し引く。在庫上限の無い伝承結晶の品目は、不足が残っていれば上と同じく不足の分の回数を入れ、残っていなければ 0 にして、回数を手で入れるよう示す。「必要」を選んだ計画の対象外の品目は、在庫上限のある品目なら在庫上限の回数にし、在庫上限の無い品目なら 0 にして、回数を手で入れるよう示す。1回の交換で得る個数が 0 以下の品目と、それ以外の品目（伝承結晶を除く足りている素材・使わない素材・「不要」の計画の対象外の品目・QP の品目）は 0 にする。操作の後の必要量・周回の内訳・合計・AP 予算は、利用者が各品目に同じ回数を入れたときと同じでなければならない (SHALL)。操作の後も、利用者は各品目の交換回数を変えられなければならない (SHALL)。育成計画・所持数・要る・要らないの選択が変わっても、入れ終えた交換回数を操作なしに変えてはならない (SHALL NOT)。

#### Scenario: 不足の分だけ交換する
- **WHEN** 素材 S の不足が 5 で、素材 S を1回に1個得る在庫上限 10 の品目があり、利用者が不足素材のみの操作をしたとき
- **THEN** その品目の交換回数は 5 になり、足りている品目・使わない品目・「不要」の計画の対象外の品目の交換回数は 0 になり、それに合う必要量と周回の合計が出る

#### Scenario: 1回に複数個得る品目
- **WHEN** 素材 S の不足が 5 で、素材 S を1回に3個得る在庫上限 10 の品目があるとき
- **THEN** 不足素材のみの操作で、その品目の交換回数は 2 になる

#### Scenario: 同じ素材の品目が複数あるとき
- **WHEN** 素材 S の不足が 5 で、交換所の元の順に、素材 S を1回に1個得る在庫上限 3 の品目と、在庫上限 10 の品目があるとき
- **THEN** 不足素材のみの操作で、前の品目の交換回数は 3、後の品目の交換回数は 2 になる

#### Scenario: 在庫上限の無い素材の品目
- **WHEN** 素材 S の不足が 7 で、素材 S を1回に1個得る在庫上限の無い品目だけがあるとき
- **THEN** 不足素材のみの操作で、その品目の交換回数は 7 になる

#### Scenario: 「必要」を選んだ計画の対象外の品目
- **WHEN** 在庫上限 1 のコード・リムーバーと、在庫上限の無い他のイベントアイテムをどちらも「必要」に選び、利用者が不足素材のみの操作をしたとき
- **THEN** コード・リムーバーの交換回数は 1 になり、他のイベントアイテムの交換回数は 0 になって、在庫上限が無いので回数を手で入れるよう示される

#### Scenario: 育成計画で使わない伝承結晶を上限まで交換する
- **WHEN** 伝承結晶の育成計画での必要数が 0 で、交換所に伝承結晶を1回に1個得る在庫上限 2・2・1 の品目が3つあり、利用者が不足素材のみの操作をしたとき
- **THEN** 3つの品目の交換回数はそれぞれ 2・2・1 になる

#### Scenario: 不足が在庫上限より少ない伝承結晶
- **WHEN** 伝承結晶の不足が 1 で、伝承結晶を1回に1個得る在庫上限 2 の品目があり、利用者が不足素材のみの操作をしたとき
- **THEN** その品目の交換回数は 2 になり、「交換所では N 個足りない」は表示されない

#### Scenario: 不足が在庫上限を超える伝承結晶
- **WHEN** 伝承結晶の不足が 5 で、伝承結晶を1回に1個得る在庫上限 2 の品目だけがあり、利用者が不足素材のみの操作をしたとき
- **THEN** その品目の交換回数は 2 になり、その品目に「交換所では 3 個足りない」と表示される

#### Scenario: 在庫上限の無い伝承結晶
- **WHEN** 伝承結晶の育成計画での必要数が 0 で、伝承結晶を1回に1個得る在庫上限の無い品目があり、利用者が不足素材のみの操作をしたとき
- **THEN** その品目の交換回数は 0 になり、在庫上限が無いので回数を手で入れるよう示される
