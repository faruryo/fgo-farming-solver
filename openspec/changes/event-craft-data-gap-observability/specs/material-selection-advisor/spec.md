# Spec Delta

## ADDED Requirements

### Requirement: 料理作成のドロップデータ欠落を画面とログで示す (Craft Drop-Data Gap Visibility)

システムは、料理作成の配分計算に入る前に、正の不足がある素材のドロップデータ欠落を検出しなければならない (SHALL)。欠落があるとき、配分計算を行ってはならない (SHALL NOT)。画面には、欠けた素材を1件ずつ、名前と欠け方とともに示さなければならない (SHALL)。欠け方は次の2種だけとする (SHALL)。

- ドロップ表にその素材が無い
- ドロップ表にはあるが、既知クエストへの正のドロップ行が無い

名前が解決できない素材は、数値の素材IDを名前の代わりに示さなければならない (SHALL)。同じ欠落の組を画面に出し続けているあいだは、本番ログへ記録するのは1回でなければならない (SHALL)。欠落の組が変わったときは、改めて1回記録しなければならない (SHALL)。記録には欠落件数と、各素材IDおよび欠け方を含めなければならない (SHALL)。所持数、必要数、アカウント識別子を記録してはならない (SHALL NOT)。ドロップ表そのものの取得失敗は、この欠落記録の対象にしてはならない (SHALL NOT)。

#### Scenario: ドロップ表に無い素材で計算を止める

- **WHEN** 正の不足がある周回対象素材がドロップ表に無く、料理作成セクションを表示するとき
- **THEN** 配分結果は表示されない。
- **THEN** 画面にはその素材の名前と、ドロップ表に無いことが含まれる。

#### Scenario: ドロップ行が無い素材で計算を止める

- **WHEN** 正の不足がある素材はドロップ表にあるが、既知クエストへの正のドロップ行が無いとき
- **THEN** 配分結果は表示されない。
- **THEN** 画面にはその素材の名前と、ドロップ行が無いことが含まれる。

#### Scenario: 複数の欠落をすべて示す

- **WHEN** 正の不足がある素材のうち、複数が異なる欠け方で欠落しているとき
- **THEN** 画面には欠落した素材がそれぞれ1回ずつ、自分の欠け方とともに出る。

#### Scenario: 名前が無い素材はIDで示す

- **WHEN** 欠落した素材の名前を解決できないとき
- **THEN** 画面にはその素材の数値IDと欠け方が出る。

#### Scenario: 同じ欠落の表示ではログは1回

- **WHEN** 同じ欠落の組が画面に出たまま、再描画だけが繰り返されるとき
- **THEN** 本番ログへの欠落記録は1回である。
- **THEN** その記録には欠落件数と、各素材IDおよび欠け方が含まれ、所持数・必要数・アカウント識別子は含まれない。

#### Scenario: 欠落の組が変わったら再記録する

- **WHEN** 画面に出ている欠落の組が、別の素材または別の欠け方に変わったとき
- **THEN** 新しい組について欠落記録が1回追加される。

#### Scenario: ドロップ表の取得失敗は欠落記録にしない

- **WHEN** ドロップ表の取得自体が失敗したとき
- **THEN** 画面は取得失敗を示し、ドロップデータ欠落としてのログ記録は行わない。

#### Scenario: 欠落が無ければ計算し記録しない

- **WHEN** 正の不足がある素材のすべてに、既知クエストへの正のドロップ行があるとき
- **THEN** 配分計算に進み、ドロップデータ欠落の画面もログ記録も出ない。
