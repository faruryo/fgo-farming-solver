# item-want-setting Specification

## Purpose
品目ごとに「欲しい」か「いらない」かを利用者が1回決めれば、交換所とアイテム一覧のどちらでも同じ設定が効き、交換所では「いらない」の品目が入力欄を持たずに表の最後へ畳まれ、その回数が計算に入らないようにする。

## Requirements

### Requirement: 品目ごとの欲しい・いらない
システムは、品目ごとに「欲しい」と「いらない」の2つのどちらかを持つ設定を設けなければならない (SHALL)。ほかの値（「自動」など）を設けてはならない (SHALL NOT)。何も設定していない品目は「欲しい」として扱わなければならない (SHALL)。設定はイベントをまたいで共通とし、どのイベントの交換所で変えても、アイテム一覧で変えても、同じ品目には同じ設定を使わなければならない (SHALL)。アイテムの品目はアイテムの番号ごとに、サーヴァント扱いの品目は獲得物ごとに設定を持ち、獲得物の番号が同じアイテムの品目とサーヴァント扱いの品目の設定を取り違えてはならない (SHALL NOT)。設定は端末に保存し、画面を開き直しても同じ設定を使わなければならない (SHALL)。この設定を使う画面は、ロトの無い交換所イベントの交換所の周回計算とアイテム一覧だけとし、ほかの画面（周回ソルバーの目標、育成計算機、クエストの効率など）の表示と計算を変えてはならない (SHALL NOT)。

この設定を入れる前に交換所の［必要｜不要］で保存した選択は、同じ保存値を次のとおりに読んで引き継がなければならない (SHALL)。「必要」と保存した品目は「欲しい」、「不要」と保存した品目は「いらない」、保存の無い品目は「欲しい」とする。前の交換所で保存せずに「不要」と表示していた計画の対象外の品目は、保存の無い品目として「欲しい」になる。

#### Scenario: 未設定の品目
- **WHEN** 利用者が一度も設定したことのない呼符を、交換所の画面で見たとき
- **THEN** 呼符は「欲しい」になっていて、交換回数の入力欄が出る

#### Scenario: 別のイベントでも同じ設定を使う
- **WHEN** 利用者があるイベントの交換所で聖杯を「いらない」にし、聖杯を並べる別のイベントの交換所を開いたとき
- **THEN** 別のイベントでも聖杯は「いらない」になっている

#### Scenario: アイテム一覧で変えた設定を交換所で使う
- **WHEN** 利用者がアイテム一覧で伝承結晶を「いらない」にしてから、伝承結晶を並べる交換所を開いたとき
- **THEN** 交換所で伝承結晶は「いらない」になっている

#### Scenario: 前に不要にした伝承結晶
- **WHEN** 利用者が前の交換所で伝承結晶を［不要］にしてから、この設定の入った交換所を開いたとき
- **THEN** 伝承結晶は「いらない」になっている

#### Scenario: 前に必要にした呼符と、何も選ばなかった計画の対象外の品目
- **WHEN** 利用者が前の交換所で呼符を［必要］にし、コード・リムーバーは選ばずに［不要］の表示のままにしてから、この設定の入った交換所を開いたとき
- **THEN** 呼符もコード・リムーバーも「欲しい」になっている

#### Scenario: 番号が同じアイテムの品目とは別に持つ
- **WHEN** サーヴァント扱いの品目と、獲得物の番号が同じアイテムの品目があり、利用者がサーヴァント扱いの品目だけを「いらない」にしたとき
- **THEN** アイテムの品目は「欲しい」のまま変わらない

#### Scenario: ほかの画面は変わらない
- **WHEN** 利用者がアイテム一覧で凶骨を「いらない」にしてから、周回ソルバーの目標の画面を開いたとき
- **THEN** 周回ソルバーの目標の画面の表示と計算は、凶骨を「いらない」にする前と同じである

### Requirement: アイテム一覧での欲しい・いらない
システムは、アイテム一覧（/items）の品目の行のうち、アイテムの番号の分かるすべての行に、「欲しい」と「いらない」の切り替えを常に表示しなければならない (SHALL)。切り替えは今の設定を示し、変えるとすぐに品目の設定を変えなければならない (SHALL)。切り替えは品目の詳細へのリンクとは別の操作にし、切り替えを押して詳細へ移ってはならない (SHALL NOT)。アイテムの番号の分からない行には切り替えを出さない。端末の設定を読み終えるまで、切り替えを未設定の「欲しい」として表示してはならない (SHALL NOT)。

#### Scenario: すべての行に切り替えが出る
- **WHEN** 利用者がアイテム一覧を開いたとき
- **THEN** アイテムの番号の分かる各品目の行に「欲しい」と「いらない」の切り替えが出て、何も設定していない品目は「欲しい」になっている

#### Scenario: 番号の分からない行
- **WHEN** アイテム一覧に、アイテムの番号の分からない品目の行があるとき
- **THEN** その行には切り替えが出ず、品目の詳細へのリンクは今までどおり使える

#### Scenario: 読み込み前に欲しいを見せない
- **WHEN** 凶骨を「いらない」にしている利用者が、アイテム一覧を読み込み直したとき
- **THEN** 設定を読み終えるまで凶骨の切り替えは「欲しい」と表示されず、読み終えると「いらない」と表示される

#### Scenario: 一覧で変える
- **WHEN** 利用者がアイテム一覧で凶骨の行の「いらない」を押したとき
- **THEN** 凶骨の行は「いらない」になり、品目の詳細のページへは移らず、ページを開き直しても「いらない」のままである

### Requirement: 交換所の品目名からの欲しい・いらない
システムは、ロトの無い交換所イベントの交換所の周回計算で、品目の行に「欲しい」と「いらない」の切り替えを常には表示してはならない (SHALL NOT)。品目名をタップしたときだけ、その品目の「欲しい」と「いらない」を選べるポップアップを出し、今の設定を示さなければならない (SHALL)。ポップアップで選ぶと、すぐに品目の設定を変え、ポップアップを閉じなければならない (SHALL)。複数の通貨で交換できる品目を1行にまとめた行は、品目が同じなので1つの設定として扱う。ポップアップは、育成計画が未設定・読み込み中・読み込みに失敗したときも使えなければならない (SHALL)。品目がすべてサーヴァント扱いの交換所の一覧（周回計算の無い一覧）には、ポップアップも次の畳んだ「いらない品目」も出してはならない (SHALL NOT)。

#### Scenario: 品目名をタップする
- **WHEN** 利用者が交換所の呼符の品目名をタップしたとき
- **THEN** 呼符の「欲しい」と「いらない」を選べるポップアップが出て、「欲しい」が選ばれている

#### Scenario: ポップアップでいらないにする
- **WHEN** 利用者が呼符のポップアップで「いらない」を選んだとき
- **THEN** ポップアップが閉じ、呼符の行は入力欄とともに一覧から消えて、表の最後の「いらない品目」に入る

#### Scenario: 育成計画が未設定でも使える
- **WHEN** 育成対象のサーヴァントが1人も設定されていない利用者が、交換所の聖杯の品目名をタップしたとき
- **THEN** 聖杯の「欲しい」と「いらない」を選べるポップアップが出る

### Requirement: いらない品目を表の最後に畳む
システムは、ロトの無い交換所イベントの交換所の周回計算で、「いらない」の品目の行を、交換回数の入力欄とともに品目の一覧から外し、一覧の最後に「▸ いらない品目 N 件」（N はその交換所の「いらない」の行の数）として畳んで表示しなければならない (SHALL)。畳んだ部分は、交換所を開いたときは閉じていて、押すと開閉しなければならない (SHALL)。開くと「いらない」の品目の名前だけを並べ、入力欄・対価・在庫上限・育成計画のラベルを出してはならない (SHALL NOT)。開いた中の名前をタップすると、交換所の品目名と同じポップアップを出し、「欲しい」を選ぶとその品目の行を、`event-shop-efficiency` の「効率順の1つの一覧」で決まる位置に戻さなければならない (SHALL)。「いらない」の品目が無い交換所では、畳んだ部分を表示してはならない (SHALL NOT)。

#### Scenario: いらない品目を畳む
- **WHEN** 利用者が聖杯と呼符を「いらない」にしている交換所を開いたとき
- **THEN** 品目の一覧に聖杯と呼符の行は無く、一覧の最後に「▸ いらない品目 2 件」が閉じた状態で出る

#### Scenario: 畳んだ部分を開く
- **WHEN** 利用者が「▸ いらない品目 2 件」を押したとき
- **THEN** 聖杯と呼符の名前だけが並び、入力欄は出ない

#### Scenario: 欲しいに戻す
- **WHEN** 利用者が開いた「いらない品目」の聖杯の名前をタップし、ポップアップで「欲しい」を選んだとき
- **THEN** 聖杯の行が入力欄とともに一覧の元の位置に戻り、「いらない品目」は 1 件になる

#### Scenario: いらない品目が無い
- **WHEN** 交換所のどの品目も「いらない」でないとき
- **THEN** 一覧の最後に「いらない品目」は出ない

### Requirement: いらない品目の回数を計算に入れない
システムは、「いらない」の品目の交換回数を、通貨ごとの選んだ交換の合計・必要量・周回の内訳・合計の周回数と AP・AP 予算・ボーナス礼装の比較に入れてはならない (SHALL NOT)。この規則は、`event-shop-single-list` の通貨ごとの選んだ交換の合計と必要量、`event-planner` のロトの無い交換所イベントの周回計画、`event-shop-ap-budget` の AP 予算、`event-drop-bonus` の交換所の周回計算への反映より優先する。品目を「いらない」にしても、その品目の保存した交換回数を消してはならず (SHALL NOT)、「欲しい」に戻したときは、保存した回数を入力欄と計算に戻さなければならない (SHALL)。保存した回数は、ほかのイベントの交換所でも同じく扱う。通貨ごとの全交換の合計（在庫上限のある品目をすべて交換するのに要る数）は交換所全体の大きさを示す値とし、「いらない」の品目も今までどおり含める。

#### Scenario: いらないにすると合計から外れる
- **WHEN** ある通貨で、呼符に 3 回（1回 20 個）、伝承結晶に 2 回（1回 200 個）を入れていて、利用者が呼符を「いらない」にしたとき
- **THEN** その通貨の選んだ交換の合計は 400 になり、必要量と周回の合計は伝承結晶の 2 回だけから出る

#### Scenario: 欲しいに戻すと回数が戻る
- **WHEN** 利用者が呼符に 3 回を入れてから「いらない」にし、その後で「欲しい」に戻したとき
- **THEN** 呼符の入力欄は 3 で、選んだ交換の合計と周回の合計に呼符の 3 回が戻る

#### Scenario: ほかのイベントの回数も入らない
- **WHEN** 利用者がイベント A の交換所で聖杯に 1 回を入れたあと、イベント B の交換所で聖杯を「いらない」にし、イベント A の交換所を開き直したとき
- **THEN** イベント A で聖杯は「いらない品目」に畳まれ、その 1 回は合計と周回数に入らない
